# 路线决策：先用 book-to-skills 转，还是直接转成教学指南？

**结论：不是二选一，是两层。** `book-to-skills` 做**原料层（L0，切章抽结构，保真）**，本模块做**教学层（L1，可教性改写）**，再往下才是**资产层（L2，教案/课件/习题/逐字稿/视频）**。
理由与判别表如下，先给判别维度，再给反例，最后给"什么情况下反过来只用 skill"。

## 一、判别表

| 维度 | 转成 skill（book-to-skills 默认路径） | 直接转成教学指南 | 教材的实际情况 → 选哪边 |
|---|---|---|---|
| 原料性质 | 书里有成体系的方法论、框架、决策规则、反模式 | 书里是知识体系、事实层级、术语定义 | 教材是**知识体系**，蒸馏会丢层级 → 指南 |
| 使用方式 | 反复查询、边干边查、跨主题跳转 | 一次性备课，但产出多个下游产物 | 一章要供 8 个模块反复引用 → 两者都要，先指南 |
| 检索粒度 | 按主题 / 章 | 按课时 / 环节 / 迷思 | 课堂按环节走 → 指南粒度更合手 |
| 保真要求 | 低（提炼即价值） | 高（术语、栏目、课标编号不能走样） | 生物学术语一字之差就是错（"原核细胞"≠"原核生物"） → 指南 |
| 上下文成本 | 4–5k 主文件 + 按需章节 | 一章 2–3k | 两者都比"整册进上下文"省，差别不大 |
| 换版成本 | 教材换版要整本重跑 | 只重跑受影响的章 | 人教版 2024 修订、2025 修订陆续到位 → 指南 |
| 典型失败 | 教材被蒸成"金句清单"，课堂没法用 | 指南写成"教材缩写"，只是换了排版 | 都要防 |

## 二、为什么 L0 不能省

1. **单一事实源。** 同一章的事实（细胞学说三条、生命系统九个层次、原核与真核的四点差别）会被教学设计、课件、习题、逐字稿同时引用。没有 L0，四份产物各写一遍，口径必然漂移（第 3 页写"一切生物都由细胞构成"，第 12 页又承认病毒没有细胞结构）。
2. **换版只换一层。** 教材修订时只重跑 L0，L1 与 L2 的改动量被限制在"受影响的概念"上。
3. **给下游一个可引用的锚。** 每条概念在 L0 里有编号（`C1.1-03`），课件、习题、逐字稿都引编号，验收时能机器检查覆盖率。

## 三、为什么 L1 必须自己做，不能靠蒸馏

拿第 1 章做对比：

| book-to-skill 会产出（蒸馏口径） | 教学实际需要（指南口径） |
|---|---|
| 框架：细胞学说三要素（发生来源 / 相对独立 / 新细胞来自老细胞） | 学生以为"细胞学说=所有生物都由细胞构成"；要用**病毒**做反例制造冲突，再回到"一切动植物" |
| 决策规则：判断某结构是否属于生命系统的某一层次 | 学生把"一个草履虫"同时算细胞层次和个体层次时卡住；需要一张"同一对象可占两个层次"的对照卡 |
| 反模式：把细胞学说归功于单人 | 教材史料的编排逻辑是"观察累积 → 归纳 → 修正"；要用 6 张史料卡做排序任务，让学生在排序中自己发现"魏尔肖是补充者" |
| 术语表：原核细胞 / 真核细胞 | 学生认为"原核细胞没有细胞器"（有核糖体）、"蓝细菌有叶绿体"（有藻蓝素和叶绿素但无叶绿体）；这两条必须进习题的错误选项 |

蒸馏产出的是**"这本书在说什么"**，教学需要的是**"学生现在怎么想、要让他经历什么才会改"**。后者不在书里。

## 四、落地：三层怎么跑

```
L0 原料层  教材一章 → chapter pack（保真切片，无解读）
              ↓ 只在这一层用 book-to-skills
L1 教学层  chapter pack → 教学指南（概念 → 迷思 → 教学动作 → 评价证据）
              ↓ 本模块 prompts/00 + 01
L2 资产层  教学指南 → 教案 / 课件 / 习题 / 逐字稿 / 视频
              ↓ 本模块 prompts/02–07
```

### L0 怎么跑（book-to-skills 的用法约束）

```
/book-to-skill <本章扫描件或文本> --mode analyze
```

- **只跑 analyze（Step 0–3）**，不要让它走完 Step 4–9 生成 `SKILL.md`。我们要它的 `structure.md` + 章节切片，不要它的"框架蒸馏"。
- 明确告知：**内容类型 = 教材/知识体系，不是方法论书**。否则它会硬凑"决策规则"。
- 生成的章包放到 `chapters/<册>/<章>/00-原料/`，并加一个 `README.md` 写明"只读、不解读、换版重跑"。
- 扫描件先 OCR（`ocrmypdf`），否则提取器会直接停下——教材 PDF 大多是图片版。
- 更省事的替代：如果只是要"概念层级 + 栏目清单"，不必上工具，直接让 Agent 读教材目录与本节标题做结构化抽取，产物同样是 chapter pack。**工具不是目的。**

### L0 的三个验收

- **保真抽检**：随机 10 个概念，逐字比对术语与数值，错一个字即 FAIL。
- **栏目齐全**：本节教材栏目（思考·讨论 / 探究·实践 / 生物科技进展 / 科学·技术·社会 / 与生物学有关的职业 / 练习与应用）一个不漏。
- **无解读混入**：L0 里出现"建议这样教""学生容易错在…"＝层级串了，移到 L1。

### L1 的三个验收

- 每个概念都有"学生会怎么想错"（没有＝还没做教学转化）。
- 每条迷思有**证据来源**（教材哪个栏目 / 常见错误 / 真题统计）与**一个教学动作**。
- 每条概念能映射到具体课时与环节（映射不上＝这章内容超载，要砍）。

## 五、什么情况下反过来，只用 skill

| 场景 | 做法 |
|---|---|
| 教研组共用"教材问答机器人"（老师随时问"这节教材怎么编排的"） | 跑完整 book-to-skill（Step 4–9），把 L0 组装成 skill，`chapters/` 即按章文件 |
| 学生自助答疑（课后问概念、要例题） | L0 → skill + L1 的迷思清单做成 FAQ；再挂 `quiz-complete` 式的刷题站 |
| 跨册检索（"光合作用在初中和高中分别讲到什么程度"） | 只建 L0 + 一张跨册概念映射表，不做 L2 |
| 备一节课 / 公开课 / 赛课 | 不要绕 L0，直接 L1 → L2；一节内容不值得建 skill |

## 六、一句话给用户的答复

> **先用 book-to-skills 把教材切成"章包"（只切不提炼），再用本模块把它转成"教学指南"，最后从指南生成教案、课件、习题、逐字稿和视频。**
> 这样做既拿到了"按章切分、按需加载"的好处，又不会让教材在蒸馏里丢掉术语、栏目和课标对应。
