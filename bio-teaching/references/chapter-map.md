# 章节地图与状态机（一章一对话）

这张表是**唯一进度源**。总控对话每次开口前读它，收工后写它。产物目录名与 ID 一一对应。

## 状态定义

| 状态 | 含义 | 判据 |
|---|---|---|
| `skeleton` | 只有章节名 | 目录未建 |
| `extracted` | 教材拆解完成 | `01-教材拆解.md` 有概念编号、≥5 条迷思 |
| `planned` | 课时与任务规划完成 | 教案头部有课时表与时间预算 |
| `designed` | 教学设计完成 | 目标-活动-评价表齐 |
| `slided` | 课件完成 | `03-课件.md` + `.pptx` |
| `quizzed` | 习题完成 | 三层题量与错因齐 |
| `ai-ready` | AI 时代教学完成 | ≥2 个融合点 + 替代方案 |
| `scripted` | 逐字稿完成 | 覆盖全部课时 |
| `ready` | 审校通过 | `check_chapter.py` 全 PASS + `index.md` 交接单 |

目录命名：`chapters/<册>/第NN章-<章名>/`，例如 `chapters/高中-必修1-分子与细胞/第01章-走近细胞/`。

知识点级不设 `planned/designed` 中间态：写完 `00-讲解设计.md` 就是 `designed`；**最小集**（6 份）+ 指南能脱离其它文档独立上课 = `ready`；加了课件/逐字稿/AI/交接单 = **完整集**（11 份），可用 `python3 scripts/check_kp.py <kp 目录>` 验收。

三件 ready 构成三种类型（七步协议的三个验证件）：

| 件 | 类型 | 冲突怎么造 | 结论 |
|---|---|---|---|
| `脱水缩合` | 能算 | 算出来的数与直觉不符 | 协议成立，最小集 32/5/0 |
| `主动运输` | 看不见、只能推 | 内外浓度数据矛盾 | 协议成立 + 两条修正 |
| `酶降低活化能` | 纯模型（算不出、无现成矛盾） | **数量级冲突**（几微克 vs 一整瓶，差几百倍） | 协议成立 + 一条修正（见 explain-protocol） |

## 推进规则

- 一批不超过 3 章，且同一批尽量同册（复用概念图与迷思库）。
- 每章开工前，把上游章的"概念编号"读进来（例如 G1-C02 需要 G1-C01 的 `C1.2-*`），避免同一概念两处定义不一致。
- 一章 `ready` 后，把"可复用的东西"回填到本表备注：可直接复用的概念图、实验、习题原型。
- 任何章节「换教材版本」→ 状态回退到 `extracted`，L0 重跑，L1 只改受影响概念。
