# 课件排版规格（v3）

> 这一份只管**字与版心**。配色与配图见 `asset-spec.md` 03c，内容分工见 `explain-protocol.md`。

一句话：**版式不是装饰，是让学生在该停的地方停一下。** 所以字号、行距、字距、标点位置都写死，不靠手感。

## 1 三套版式的字号阶（单位 px @1280×720）

| 层级 | 字体 | A 学术冷版 | B 课堂暖版 | C 教材版 | 说明 |
|---|---|---|---|---|---|
| 封面主标题 | 宋体 700 | 54 | 64 | 56 | 3 行以内；按 560px 宽自动降号 |
| 内页标题 | 宋体 700 | 33–38 | 38–44 | 33–36 | 一行读完；不换行优先 |
| 大数字（hero） | 宋体 700 | 104 | 120 | 104 | 两个数字对撞，中间留 40–96 |
| 正文 | 苹方/雅黑 400 | 19 | 22 | 20 | 一屏 ≤ 3 行，一行 ≤ 32 字 |
| 表体 | 黑体 | 19 | 22 | 20 | 首列宋体 700 当\"行首\" |
| 图注 | 宋体 400 斜体 | 12.5 | 13.5 | 12.5 | 写成\"这是什么\"，不写形容词 |
| kicker | 黑体 500 | 11.5（字距 4.4） | 14.5（字距 1.6） | 12.5（字距 2.2） | 全页唯一的大字距小字 |
| 页脚 | 黑体/宋体 | 11 | 21（页码） | 10.5 + 15（页码框） | 页码是版式的一部分，不是附注 |

`classroom` 的实现方式不是逐处改数，而是全局 `scale=1.15`：**字号与竖向节奏一起放大**，版心不变——所以它看起来是\"同一版式放大\"，不是\"字变大了、行挤在一起\"。

## 2 中文排版的三条硬规则（已写进代码）

1. **禁则**：行首不排 `。，、；：？！）》」』`，行尾不留 `（《「『`。`wrap()` 遇到收尾标点做悬挂，遇到起首标点把它推到下一行。
2. **孤字控制**：末行只剩一个字时，从上一行借一个字下来（宁可上一行紧一毫米，不留一个吊着的字）。
3. **段落是一个文本对象**：同一段的多行合并成 `<text>` + `<tspan dy>`，转成 PPTX 后是**一个可编辑文本段**，不是几个文本框。改一个字不会让整页重排。

字距只给三类元素：标题 `0.015–0.045em`（学术版最松）、kicker `+2.2~4.4px`、其余一律 0。**正文字距永远是 0**——中文正文字距一松，行读起来就散。

## 3 行距与留白

| 场景 | 行距 | 段间距 |
|---|---|---|
| 封面标题 | 1.16 | — |
| 内页标题 | 1.12 | 后接 30 |
| 正文 | 1.5 | 条目间 +22 |
| 引语 / 定义页 | 1.2 | — |
| 表格行 | 54（含线） | 行下 22 处画线 |
| 图注 | 距图 26 | — |

版心边距固定 76，页脚线 654，页码基线 682。任何内容不许压过 654——`fit()` 同时受**宽、高、行数**三重约束，超了就降号，不靠手调。

## 4 页面机件（三套各不同）

- **A 学术冷版**：顶部 60 处一条通栏细线，左端 44px 压一道 1.6px 红线；右上 running head（章名，字距 2.8）。底部 `01 / 15` + 右侧 colophon「单墨 · 教学图版」。赤陶只在细线与数据标记里出现，**不做色块**。
- **B 课堂暖版**：kicker 前是一道手写起伏线；标题下 8px 一道 3.2px 手写横线；页码 21px 赤陶衬线 + `/15`。手写元素全部是路径（`hand_rule` / `hand_circle`），半径与起伏刻意不齐——**整齐的手写是假的**。
- **C 教材版**：顶部章名 + 一粗一细双线；左侧 12px 竖条（6% 墨）；标题自动加「一、二、」；图注统一 `图 5-1`；右下 56×28 页码框。像人教版，但只用它的**语法**，不复刻版式。

## 5 自检（没有渲染器也要能查）

沙箱里没有中文字体、没有 libreoffice、没有 libcairo，**没法把 SVG 渲染成图**。所以用三个可计算的替代品：

```sh
python3 scripts/check_overflow.py <构建目录>     # 越界 / 相撞 / 行距过挤
python3 /home/user/ppt-master/skills/ppt-master/scripts/svg_quality_checker.py \
        <构建目录> --quick-generate --canonical-authoring --stage final
python3 -c "from pptx import Presentation as P; ..."   # 页数 / 图片数 / 备注数
```

判定：越界 0、相撞 0、行距过挤 0、quality checker 0 阻塞 0 advisory。**\"够不够高级\"这一步脚本判不了，必须给人看预览页。**

## 6 换版式只改一个参数

```sh
python3 scripts/build_deck.py --md "kp/…/06-课件.md" --plan "kp/…/06-课件.plan.json" \
  --out /tmp/deck-C --images assets/deck-images/src --theme textbook --tag="-C教材"
```

`--theme` 四个取值：`academic` / `classroom` / `textbook` / `plate`。同一份 plan 换主题重跑即可，不需要第二份 plan，也不需要复制 md。

## 7 动画（`-含动画.pptx`）

动画不在 SVG 里做，做完 pptx 再灌：`scripts/animate_pptx.py in.pptx out.pptx`。

| 规则 | 说明 |
|---|---|
| 分块 | 按**文档顺序**聚类，同一个内容块一起出现；块间距 < 24px 归为一块 |
| 满版底图 | 盖满整页的图/底色永远是第 0 块，随页面自动出现 |
| 首块 | 标题块自动；封面与收尾页整体自动（不进点击序列） |
| 其余 | 每次点击淡入一块，0.5s；页脚并进最后一块，不单独点 |
| 上限 | 单页最多 6 块，超过就合并最短的相邻块 |
| 目标 | **一步 = 一次点击 = 一组叶子形状**：每块里每个形状各写一条效果（首条 `clickEffect`、其余 `withEffect`）。不打包成组合——组合是 WPS 最常见的"没动画"原因 |
| 不动坐标 | 不动 `spTree`，不动任何 xfrm；只追加一段 `<p:timing>` |
| 效果 | **按块形状选效果**：整块用 `fade`；宽扁块（高 ≤150px 且宽 ≥620px，如表格行、通栏条）用 `wipe(up)`，让"一行一行推进"看得见 |

### 7.1 逐行 / 逐句（"一行一行推进"）

两块能力，一个原则：**只在列表和表格上拆，图绝不拆**。

1. **句子边界不合并**（`build_deck.merge_text_runs`）：连续单行 `<text>` 默认并成一段（编辑友好），
   但**上一行以 。！？； 结尾就断开**——一句一个文本框，才可能一句一次点击。
   长句折行时前几行不以句号结尾，仍然并进同一段。
2. **按行带拆块**（`animate_pptx.list_rows`）：块内若有 ≥3 条**同左边缘（±5px）、等距下落、单行高 ≤80px** 的文本，
   一条一步；落在该行区间里的底色/序号/分隔线跟着这一行走。
   拿不到这样"列"的页面（坐标轴、散点标注、能量图）自动放弃——否则一张图会被拆成十几步，讲不成一句完整的话。

上限：常规 ≤6 块，允许拆分时 ≤9 块（`6 < n ≤ 9` 才启用拆分，否则回退整块）。

### 7.2 用哪个 filter：presetID 必须配对

`p:animEffect` 的 `filter` 和 `presetID` 是两个字段，写错不报错、能播，但 PowerPoint 的动画窗格会标成别的效果。
下表是**实测可播**的组合（来源：`pptx-animation-skill` 的 `oracle/`，逐条视觉验证）：

| 名 | filter | presetID | 方向值 | 时长 | 用途 |
|---|---|---|---|---|---|
| fade | `fade` | **9**（不是 10，10 是 dissolve） | — | 500ms | 默认、封面整体 |
| wipe | `wipe(up)` | 22 | 1 | 420ms | 宽扁块、表格行 |
| reveal | `wipe(left)` | 22 | 8 | 460ms | 预留 |
| circle | `circle(in)` | 18 | 12 | 480ms | 强调点（未启用） |

`p:animEffect` 必须与 `p:set` 的 `style.visibility` 配对才可见；而 `p:anim` 打在 `fill.opacity` / `stroke.weight` 上是**死路径**（解析通过、播放静默丢弃）——不要用。

## 7.3 曲线要原生图表，不要路径

SVG 里画的曲线到 pptx 里是 Freeform：能看不能改。定量曲线（温度/底物浓度/反应进程）一律走原生图表：

```sh
python3 scripts/native_chart.py deck.pptx deck-charts.json
```

- `build_deck.py` 画图时把**同一份采样点**写进 `<stem>-charts.json`（81 点，0–1 归一化）；
- 脚本删掉整块画在图区矩形内的元素（标题/页脚在区域外，不受影响），在原位插 `XY_SCATTER_SMOOTH_NO_MARKERS`；
- 图表挪进 `content` 组，动画照样能引用；刻度数字隐藏（示意图形，写具体数值是假数据）。

## 8 字体：PowerPoint 里改的是"主题槽"，不是 run

**踩过的坑**：`ppt-master` 生成的主题里 `majorFont` 与 `minorFont` **都是 SimSun**。
所有文字都写 `+mj-lt` / `+mn-lt`（这是对的，便于统一换字体），但如果主题两个槽一样，
预览里"标题宋体 + 正文黑体"的层次到 PowerPoint 里就塌成**通篇宋体**——看起来很"教材"，
但一行正文超过 30 字就会糊成一片。转换器不会替你分开，必须导出后改主题：

`scripts/build_deck.py` 导出后自动调用 `scripts/polish_pptx.py <src> <dst>`：

| 槽 | 拉丁 | 东亚 |
|---|---|---|
| major（标题） | Times New Roman | SimSun |
| minor（正文/表格） | Arial | Microsoft YaHei |

同时给 `<p:pic>` 的 `cNvPr` 写 `descr`（图片替代文字，无障碍 + 教务检查会看）。
**只处理 `p:pic` 里的 `cNvPr`**——对所有 `cNvPr` 加 descr 会把形状、组合也标成"课程配图"（实测一次 289 条）。

改完必须回 PowerPoint 里看一眼：标题应当是**宋体/衬线**，正文与表格应当是**黑体/无衬线**。

兼容：`--simple` 把 wipe 全退化成 fade（老 WPS 不认方向 filter 时用）；`--group` 回到"打包成组合"的老做法（只在纯 PowerPoint 环境用）。
自检：`python3 scripts/check_animation.py xxx-含动画.pptx` 判七条结构（目标是否组合 / id 唯一 / spTgt 命中 / 点击组 delay / filter 白名单）；
`python3 scripts/animate_pptx.py in.pptx out.pptx` 会打印每页「N 块 → X 自动 + Y 次点击」；
生成后可再用 python-pptx 打开，检查每页 id 不重复、`spTgt` 目标都存在。
