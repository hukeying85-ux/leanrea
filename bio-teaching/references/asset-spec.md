# 产物规格与验收 gate

验收只有两种结果：PASS / FAIL。FAIL 必须指出**改哪一行、改成什么**，不接受"再润色一下"。
`scripts/check_chapter.py` 能自动查的部分标 🤖，其余靠人（或 Agent 逐条比对）。

## 通用命名

```
chapters/<册>/第NN章-<章名>/
  00-原料/            L0 章包（book-to-skills 产物，只读）
  01-教材拆解.md      L1 起点
  02-教学设计.md      教案（含课时表）
  03-课件.md          课件大纲（build_pptx.py 的输入）
  03-课件.pptx        生成物
  04-习题检验.md      教师版（含答案与解析）
  04-习题-学生版.md   只留题面（可直接印）
  05-AI时代教学.md
  06-逐字稿.md
  07-视频演示.md
  index.md            交接单（ready 时生成）
```

## 00 教材拆解（`01-教材拆解.md`）

| 项 | 规格 | 检查 |
|---|---|---|
| 概念编号 | `C<课标编号>-NN`，如 `C1.1-03`，全章连续不跳号 | 🤖 正则与连续性 |
| 概念层级 | 大概念 → 重要概念 → 次位概念，只写到次位概念 | 🤖 三级都在 |
| 概念数 | 每节 3–6 条次位概念；超过 6 条说明该节要拆课时 | 🤖 |
| 迷思概念 | ≥5 条/章，每条含：学生怎么说 / 错在哪 / 证据来源 / 一个教学动作 | 人查 |
| 教材栏目 | 思考·讨论 / 探究·实践 / 生物科技进展 / 科学·技术·社会 / 与生物学有关的职业 / 练习与应用，逐项列本节用到哪些 | 🤖 关键词命中 |
| 命题点 | 3–5 条，每条指回"册-章-节-栏目" | 人查 |
| 跨章连接 | 上游（已学）/ 下游（将学）各 ≥2 条 | 人查 |

## 01–02 教学设计与教案（`02-教学设计.md`）

| 项 | 规格 | 检查 |
|---|---|---|
| 课时表 | 课时数 × 45 min，标注课型（新授/复习/实验/习题） | 🤖 |
| 时间预算 | 每课时 讲授:活动:评价 ≈ 4:4:2，合计 45±2，新增环节必须显性扣减 | 🤖 求和 |
| 学习目标 | 每条含 行为动词 + 内容 + 条件 + 标准（ABCD）；动词可观察 | 人查 |
| 目标—活动—评价表 | 三列一一对应，任一目标没有评价即 FAIL | 🤖 行数/空值 |
| 问题链 | ≥1 条主问题 + 3–5 个子问题；子问题标注"良构/劣构" | 🤖 |
| 认知冲突 | 每课时 ≥1 处，写明"学生原以为 X，证据 Y 指向 Z" | 人查 |
| 活动产出物 | 每个学生活动写清产出什么（卡片/表格/图/一句话） | 人查 |
| 迷思覆盖 | 本章迷思在活动中被正面处理的 ≥ 2/3 | 🤖 编号引用 |

## 03 课件（`03-课件.md`）

Markdown 约定（`build_pptx.py` 解析）：

```markdown
# 课件标题
> 副标题（册 · 章 · 课时）

## 01 封面标题
- 要点一
- 要点二
<!-- note: 讲稿备注，进 pptx 备注页 -->

## 02 下一页标题（结论句）
| 左 | 右 |
| --- | --- |
| A | B |
```

| 项 | 规格 | 检查 |
|---|---|---|
| 页数 | 课时数 × 8–10，误差 ±4 | 🤖 |
| 页面字数 | 正文 ≤45 字（不含表格与图注） | 🤖 |
| 标题 | 结论句，不是名词短语（"细胞是生命活动的基本单位" ✅ /"细胞学说" ❌） | 人查（抽查 5 页） |
| 每页一个认知动作 | 一页只做一件事：立概念 / 给反例 / 做对比 / 提任务 / 收结论 | 人查 |
| 迷思反例页 | ≥1 页专门放"常见错误说法 + 为什么不成立" | 🤖 关键词 |
| 备注页 | 每页都有 `<!-- note: -->`，与逐字稿同源 | 🤖 覆盖率 ≥ 90% |
| 无原文搬运 | 不出现连续 ≥30 字与教材一致的段落 | 人查 |
| 生成物 | `.pptx` 可打开；`03-课件-preview.html` 单文件离线可翻页 | 🤖 文件存在 |

## 04 习题（`04-习题检验.md`）

| 项 | 规格 | 检查 |
|---|---|---|
| 题量 | 基础 40% / 应用 40% / 迁移 20%；每课时 ≥5 题 | 🤖 |
| 题型 | 选择、填空、识图/图表、简答（论证）、实验分析，至少 4 类 | 🤖 |
| 诊断标注 | 每题标 `[C1.1-03]` 概念编号 + `[M2]` 迷思编号 + 错因归类 | 🤖 |
| 答案与解析 | 教师版每题有解析，解析说明"错选项对应哪条迷思" | 人查 |
| 变式 | 每题组至少有 1 条变式（换情境不换考点） | 🤖 |
| 学生版 | 无答案、无解析、无教师提示 | 🤖 关键词不在 |
| 不编造真题 | 引用真题标注来源年份地区；改编标"改编" | 人查 |

## 05 AI 时代教学（`05-AI时代教学.md`）

| 项 | 规格 | 检查 |
|---|---|---|
| 融合点 | ≥2 个，每个含：AI 做什么 / 学生判断什么 / 没有 AI 怎么替代 / 需要什么工具 | 🤖 四栏 |
| 幻觉检测 | ≥1 个具体例子（AI 常错的那个说法 + 学生怎么核验） | 人查 |
| 评价改造 | 无 AI / AI 辅助 / AI 整合 三类各给 1 个评价方式 | 🤖 三类齐 |
| 学术诚信 | 写明本课的学生 AI 使用声明规则 | 人查 |
| 工具中立 | 不绑定单一产品；写"任意能读图的模型"而不是某 App | 人查 |

## 06 逐字稿（`06-逐字稿.md`）

| 项 | 规格 | 检查 |
|---|---|---|
| 覆盖 | 至少 1 个完整课时；其余课时给"关键句 + 过渡语" | 人查 |
| 时长 | 朗读字数 ≈ 课时 × 0.55 × 220 字/分钟（45 min ≈ 5400 字上限，含停顿） | 🤖 估算 |
| 标记 | `[停 3s]` `[板书：…]` `[追问]` `[看第 N 页]` `[走动]` | 🤖 标记数 ≥ 15/课时 |
| 口语 | 单句 ≤25 字；禁用"综上所述/鉴于此/众所周知" | 🤖 关键词 |
| 互动点 | 每 5 分钟 ≥1 个互动（提问/手势/同桌说） | 🤖 |

## 07 视频演示（`07-视频演示.md`）

| 项 | 规格 | 检查 |
|---|---|---|
| 受众契约 | 先说清"给谁看、看完能回答哪个问题、多长" | 人查 |
| 分镜表 | 时间码 / 画面 / 旁白 / 字幕 / 动效，逐行对齐 | 🤖 四列齐 |
| 时长 | 单条 ≤3 min；概念片建议 60–120 s | 🤖 |
| 旁白同步 | 每个动画触发点绑定旁白关键词（说到"核膜"才画核膜） | 人查 |
| 实现路线 | 给出可跑命令：最低成本（ffmpeg 图文）与进阶（manim）两条 | 🤖 命令块存在 |
| 事实核验 | 画面里出现的数值/结构名称逐条核对 | 人查 |

## 08 审校与交接（`index.md`）

- 跑 `python3 scripts/check_chapter.py <章目录>`，0 FAIL。
- 填事实核验表：本页/本课出现的每个专有名词与数值，来源何处（教材栏目 / 课标 / 权威站点）。
- 版权：无教材原文段落；图片为自制或授权。
- AI 声明：哪些内容是 AI 起草、哪些经教师改写。
- 已知缺口：明确写"待实测/未渲染/未录课"，不粉饰。

## 一票否决项

1. 出现与教材连续 ≥30 字一致的原文。
2. 目标—活动—评价表有三缺一。
3. 习题没有诊断标注（无法定位到概念/迷思）。
4. AI 环节没有学生判断动作，只是"让 AI 生成"。
5. 逐字稿无法覆盖本节核心概念（说明教学设计与稿子脱节）。
6. 谎报课堂效果（写"学生掌握良好"却没有实测）。
