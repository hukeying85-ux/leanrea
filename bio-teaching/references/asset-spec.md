# 产物规格与验收 gate

验收只有两种结果：PASS / FAIL。FAIL 必须指出**改哪一行、改成什么**，不接受"再润色一下"。
`scripts/check_chapter.py` 能自动查的部分标 🤖，其余靠人（或 Agent 逐条比对）。

## 通用命名

```
chapters/<册>/第NN章-<章名>/
  00-原料/            L0 章包（book-to-skills 产物，只读）
  01-教材拆解.md      L1 起点
  02-教学设计.md      教案（含课时表）
  03-课件.md          课件大纲（内容层）
  03-课件.plan.json   版式层（每页 layout / 配图）
  03-课件-<版本>.pptx  生成物：A学术 / B课堂 / C教材 三版
  04-习题检验.md      教师版（含答案与解析）
  04-习题-学生版.md   只留题面（可直接印）
  05-AI时代教学.md
  06-逐字稿.md
  07-视频演示.md
  index.md            交接单（ready 时生成）
```

## 00 教材拆解（`01-教材拆解.md`）

| 项 | 规格 | 检查 |
|---|---|---|
| 概念编号 | `C<课标编号>-NN`，如 `C1.1-03`，全章连续不跳号 | 🤖 正则与连续性 |
| 概念层级 | 大概念 → 重要概念 → 次位概念，只写到次位概念 | 🤖 三级都在 |
| 概念数 | 每节 3–6 条次位概念；超过 6 条说明该节要拆课时 | 🤖 |
| 迷思概念 | ≥5 条/章，每条含：学生怎么说 / 错在哪 / 证据来源 / 一个教学动作 | 人查 |
| 教材栏目 | 思考·讨论 / 探究·实践 / 生物科技进展 / 科学·技术·社会 / 与生物学有关的职业 / 练习与应用，逐项列本节用到哪些 | 🤖 关键词命中 |
| 命题点 | 3–5 条，每条指回"册-章-节-栏目" | 人查 |
| 跨章连接 | 上游（已学）/ 下游（将学）各 ≥2 条 | 人查 |

## 01–02 教学设计与教案（`02-教学设计.md`）

| 项 | 规格 | 检查 |
|---|---|---|
| 课时表 | 课时数 × 45 min，标注课型（新授/复习/实验/习题） | 🤖 |
| 时间预算 | 每课时 讲授:活动:评价 ≈ 4:4:2，合计 45±2，新增环节必须显性扣减 | 🤖 求和 |
| 学习目标 | 每条含 行为动词 + 内容 + 条件 + 标准（ABCD）；动词可观察 | 人查 |
| 目标—活动—评价表 | 三列一一对应，任一目标没有评价即 FAIL | 🤖 行数/空值 |
| 问题链 | ≥1 条主问题 + 3–5 个子问题；子问题标注"良构/劣构" | 🤖 |
| 认知冲突 | 每课时 ≥1 处，写明"学生原以为 X，证据 Y 指向 Z" | 人查 |
| 活动产出物 | 每个学生活动写清产出什么（卡片/表格/图/一句话） | 人查 |
| 迷思覆盖 | 本章迷思在活动中被正面处理的 ≥ 2/3 | 🤖 编号引用 |

## 03 课件（`03-课件.md`）

两处都要放（本轮修正）：`.pptx` 同时进 git 与 Drive。理由是教师找不到课件就等于没交付；Drive 只读副本不承担版本管理，源始终是 md。
生成走 `scripts/build_deck.py`（见 03c）：页数 gate = 课时数 × 9 ± 4，由 `check_chapter.py` / `check_group.py` 验。


Markdown 约定（`build_deck.py` 解析）：

```markdown
# 课件标题
> 副标题（册 · 章 · 课时）

## 01 封面标题
- 要点一
- 要点二
<!-- note: 讲稿备注，进 pptx 备注页 -->

## 02 下一页标题（结论句）
| 左 | 右 |
| --- | --- |
| A | B |
```

| 项 | 规格 | 检查 |
|---|---|---|
| 页数 | 课时数 × 8–10，误差 ±4 | 🤖 |
| 页面字数 | 正文 ≤45 字（不含表格与图注） | 🤖 |
| 标题 | 结论句，不是名词短语（"细胞是生命活动的基本单位" ✅ /"细胞学说" ❌） | 人查（抽查 5 页） |
| 每页一个认知动作 | 一页只做一件事：立概念 / 给反例 / 做对比 / 提任务 / 收结论 | 人查 |
| 迷思反例页 | ≥1 页专门放"常见错误说法 + 为什么不成立" | 🤖 关键词 |
| 备注页 | 每页都有 `<!-- note: -->`，与逐字稿同源 | 🤖 覆盖率 ≥ 90% |
| 无原文搬运 | 不出现连续 ≥30 字与教材一致的段落 | 人查 |
| 生成物 | `.pptx` 可打开；`03-课件-preview.html` 单文件离线可翻页 | 🤖 文件存在 |

## 04 习题（`04-习题检验.md`）

| 项 | 规格 | 检查 |
|---|---|---|
| 题量 | 基础 40% / 应用 40% / 迁移 20%；每课时 ≥5 题 | 🤖 |
| 题型 | 选择、填空、识图/图表、简答（论证）、实验分析，至少 4 类 | 🤖 |
| 诊断标注 | 每题标 `[C1.1-03]` 概念编号 + `[M2]` 迷思编号 + 错因归类 | 🤖 |
| 答案与解析 | 教师版每题有解析，解析说明"错选项对应哪条迷思" | 人查 |
| 变式 | 每题组至少有 1 条变式（换情境不换考点） | 🤖 |
| 学生版 | 无答案、无解析、无教师提示 | 🤖 关键词不在 |
| 不编造真题 | 引用真题标注来源年份地区；改编标"改编" | 人查 |

## 06 逐字稿（`06-逐字稿.md`）

| 项 | 规格 | 检查 |
|---|---|---|
| 覆盖 | 至少 1 个完整课时；其余课时给"关键句 + 过渡语" | 人查 |
| 时长 | 朗读字数 ≈ 课时 × 0.55 × 220 字/分钟（45 min ≈ 5400 字上限，含停顿） | 🤖 估算 |
| 标记 | `[停 3s]` `[板书：…]` `[追问]` `[看第 N 页]` `[走动]` | 🤖 标记数 ≥ 15/课时 |

| 互动点 | 每 5 分钟 ≥1 个互动（提问/手势/同桌说） | 🤖 |

## 03c 课件版式（PPT Master 通道）

`03-课件.md` / `06-课件.md` 只写**内容**（页 → 要点 → 备注）。版式是另一层：`<stem>.plan.json` 指定每页的 `layout` 与配图，`scripts/build_deck.py` 生成 1280×720 SVG，再由 PPT Master（MIT，`hugohe3/ppt-master`）转成**原生** PPTX（文字可编辑、图片原生、曲线是路径）。

### 配图：铜版画原图（v3）

v2 的"四种材料拼贴"已经判死：写实照片、3D 渲染、水彩、风景照混在一套课件里，怎么调间距都救不回来。v3 从**生成端**就只出一种画风——十九世纪铜版／木刻版画：细密交叉排线、单墨印在暖纸上、**图内零文字零标注**。

| 文件（`assets/deck-images/src/`） | 用在哪 |
|---|---|
| `tubes` | 封面 · 自由扩散（三支试管，中间冒泡） |
| `splint` | 现象页 · 断电实验（带火星木条） |
| `flask` | 双大数字页（锥形瓶里密集气泡） |
| `enzyme` | 关键一问（折叠蛋白托住底物） |
| `cell` | 植物细胞剖面（细胞壁 / 液泡 / 叶绿体 / 胞间连丝） |
| `onion` | 质壁分离（细胞壁与收缩的原生质体之间的空隙） |
| `membrane` | 脂双层 + 通道蛋白 |
| `root` | 根尖纵剖 + 根毛 |
| `stomata` | 气孔与保卫细胞 |
| `saltfield` | 封面 · 收句（盐碱地上的稻穗） |

构建时按主题重新上色，出 `-light`（纸底）/ `-ink`（墨底）两版，**纸色与页面同色**，所以图片可以 `meet` 放进版面而不露边框。曲线与格线见 `references/typography.md`。

### 三套版式（`--theme`）

同一份 md + 同一份 plan，只换 `--theme`，就能出三种气质；几何与版式集合完全相同，差的是**纸墨、字号、页面机件**。

| `--theme` | 名字 | 纸 / 墨 | 字 | 页面机件 | 适用 |
|---|---|---|---|---|---|
| `academic` | A 学术冷版 | `#F1F0EB` / `#111E20`，只有一条细红线 `#9E2B1B` | 正文 19、标题字距 0.045em | 顶部通栏细线 + 右上 running head；底部 `01 / 15` + 小字 colophon | 公开课、教研、评审 |
| `classroom` | B 课堂暖版 | `#FAF3E3` / `#1A2A26`，赤陶 `#B94E2A` + 赭黄 `#B5852B` | 整体 **×1.15**（正文 22、标题 64） | 手写感圈画、标题下手写横线、页码大号衬线 | 真实教室，后排也要看得清 |
| `textbook` | C 教材版 | `#F7F4EA` / `#16282A` | 正文 20、标题前缀「一、二、」 | 顶部章名 + 双细线、右侧固定页码框、图注统一「图 5-1」 | 印发、归档、学生课后看 |
| `plate` | 单墨基准（v2 对照） | `#F4EFE4` / `#14302F` | 正文 20 | 页脚 `NN — MM` | 只作对照组，不再单独交付 |

12 种版式：`cover` `plate` `plate_side` `hero` `diagram` `chart` `table` `compare` `checklist` `quote` `section` `statement`。

**四条硬规则**：

1. **图不承载信息**。图里不写字、不标箭头、不标数字；要被读的关系（曲线两端、平台高度、原生质层位置）画成矢量或写成文字。
2. **隐喻要画，不要拍照**。"能量要翻一座山""酶打了一条隧道"——用 `diagram` 版式原生画；风景照会让课件从生物学滑向旅游海报。
3. **配图只准来自 `assets/deck-images/src/`**。混入照片、3D 渲染、水彩即为退稿，重生成不要打补丁。
4. **改内容改 md，改样子改 plan.json**，重跑 `build_deck.py` 得新 pptx；不要手改 pptx。

## 03b 章级成组（`chapters/<册>/第NN章-<章名>/`，多知识点串成一章）

`check_chapter.py` 管单份文件合不合规；成组另有口径，用 `check_group.py` 验收。

| 项 | 规格 | 检查 |
|---|---|---|
| 成组件 | 必须有 `00-课时切分与成组.md`（单章可省） | `check_group.py` |
| 主线 | 一个可命名的情境，贯穿设计 / 课件 / 逐字稿 | 🤖 关键词三处命中 |
| 切分口径 | 按"判据的栏数"切，不按教材页数切 | 人查 + 脚本查"加列"字样 |
| 一张表 | 跨课时用同一张表，**逐课时加一列**，不新画表 | 🤖 三栏齐 |
| 钩子 | ≥3 个，全部标注埋点与回收课时 | 🤖 埋点/回收计数 |
| 重复自查 | 每个内容"只准讲一次、用一次"，列成表 | 🤖 含"讲一次" |
| 课时密度 | 课件页数 / 课时数 ∈ 6–10 | 🤖 |
| 与知识点分工 | 章讲"怎么排"，`kp/` 讲"怎么讲"，不互相抄 | 人查 |
| 验收命令 | `python3 scripts/check_group.py "chapters/<章目录>"`，0 FAIL | 人+脚本 |

## 08 审校与交接（`index.md`）

- 跑 `python3 scripts/check_chapter.py <章目录>`，0 FAIL。
- 填事实核验表：本页/本课出现的每个专有名词与数值，来源何处（教材栏目 / 课标 / 权威站点）。
- 版权：无教材原文段落；图片为自制或授权。
- AI 声明：哪些内容是 AI 起草、哪些经教师改写。
- 已知缺口：明确写"待实测/未渲染/未录课"，不粉饰。

## 一票否决项

1. 出现与教材连续 ≥30 字一致的原文。
2. 目标—活动—评价表有三缺一。
3. 习题没有诊断标注（无法定位到概念/迷思）。
4. AI 环节没有学生判断动作，只是"让 AI 生成"。
5. 逐字稿无法覆盖本节核心概念（说明教学设计与稿子脱节）。
6. 谎报课堂效果（写"学生掌握良好"却没有实测）。
