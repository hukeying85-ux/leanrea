# 课件配图：14 张原图 → 28 张"单墨版画"

## 为什么要有这一步

第一版配图是"四种材料拼贴"：写实实验室照片、3D 分子渲染、水彩细胞、风景照（山、隧道、学生）。单看都还行，放在一套课件里就是**四种画风**——这正是"图跟生物学不像一套"的根子。

第二版做了两件事：

1. **换掉不属于生物的意象**。山、隧道、教室照片退出配图，改用**原生矢量图**来画（能量垭口、隧道、判据表）——隐喻本来就该被画出来，而不是找一张风景照替它。
2. **统一成"单墨双色版画"**。所有照片先过 `scripts/duotone.py`，压到「暖纸 #F4EFE4 + 深松墨 #14302F」两个色阶，出浅版（纸底）和深版（墨底）两个文件。混合媒介立刻读成同一套图版——这正是老生物学教材的视觉语言。

```
assets/deck-images/<name>-light.jpg   浅版：纸底、墨线，用于浅色页的嵌版图
assets/deck-images/<name>-ink.jpg     深版：墨底、亮部收窄，用于整版图 / 深色分隔页
```

## 14 张原图与提示词摘要

全局约束：**图里不放任何文字、标注、箭头、数字**。需要被"读"的关系（三条曲线两端重合、平台高度、原生质层收缩）一律用原生矢量或表格画。

| 文件 | 用在哪 | 提示词要点 |
|---|---|---|
| `tubes` | 酶封面 / 自由扩散 | 三支试管木架，中间剧烈冒泡，左清右浊，晨光侧射 |
| `splint` | 现象页 / 断电实验 | 戴手套持带火星木条，一缕烟，暗调实验室 |

| `enzyme` | 关键一问 / 换催化剂 | 深青折叠蛋白托住琥珀色底物，接触处微光，3D 渲染 |

## 派生

```sh
python3 scripts/duotone.py <原图目录> assets/deck-images --width 1500
```

- 浅版曲线：自动对比 → 对比度 1.15 → gamma 0.58（提亮中间调，让纸白透出来）
- 深版曲线：自动对比 → 对比度 1.10 → 深墨 #0B1819 → 哑光青 #566C64（压住高光，白字压得住）

原图由 Arena 内置图像模型生成（2026-11-03）。**只承担氛围与形态，不承担任何事实标注**；教材里要精确的地方（曲线、判据、结构位置）都用矢量画。
