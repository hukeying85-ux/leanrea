# 生物学教学模块：一章 → 全套教学资产

> 一个知识点能不能让一个学生**在 40 分钟内真的懂**，是这套东西唯一的验收标准。
> 课件不是教材搬运，是"替老师把话说到位"。

## 0 三句话

1. **顺序不能倒**：先调研（教材 + skills），再规划任务，再做产物。反过来就是"用模板套内容"，一眼假。
2. **粒度分层**：章是**生产单位**（交付、验收都按章），知识点是**讲解单位**（怎么讲好）。两者不能混。
3. **脚本能判的只有"合规"**，"高级"必须给人看。所以每轮都要出**预览页**，不许只交 pptx。

## 1 什么时候用 / 不用

| 用 | 不用 |
|---|---|
| 有明确章节边界、要一次性交付成套资产 | 只是写一段文案、改错别字 |
| 需要"讲得懂"而不只是"覆盖知识点" | 只需要知识点清单/思维导图 |
| 允许产物落盘、可复跑、可验收 | 一次性口头回答，不需要留文件 |

## 2 三条不可倒置的顺序

```
① 调研教材（这一章在教材里怎么排、前置是什么、考试怎么考）
      ↓
② 调研 skills（现成能力盘点：能不能少造轮子、别人踩过什么坑）
      ↓
③ 规划任务（课时切分、任务清单、每课时的产判断据）
      ↓
④ 生产产物（教案 → 讲解设计 → 课件 → 习题 → AI → 逐字稿 → 视频）
```

**为什么 ① 在 ② 前面**：教材决定"必须讲到什么"，skills 决定"用什么工具讲"。反过来会被工具牵着走，产出全是版式没有内容。
**为什么 ② 不能省**：本轮（2026-11）实测，教学法层**没有**现成可用 skill，但**动画 XML 词表、风格库、自检思路**三类能直接借——省下来的时间够把一章的配图重做两遍。

**输入**：一章教材（人教版初中 2024/2025 修订版、高中 2019 版）或一个知识点 + 学段 + 课时数。

**产出**（`chapters/` 按章，`kp/` 按知识点）：

## 4 九步流水线

### 4.1 章节地图与任务规划
把章拆成课时，每课时写出**一句"下课时学生应该能做什么"**（可观测动词：说出/排出/画出/解释为什么）。
判据表三栏：**方向、载体、能量**——凡涉及物质运输/信号/代谢，这三栏一填，课时边界自然出现。
产物过 `check_chapter.py`。

### 4.2 教学设计（教案）
- 目标必须可观测，不许"理解""掌握"。
- 问题链：3–5 问，每问有**认知落差**（学生一定会答错的那个答案是什么，写下来）。
- 每个活动标时长；一课时总时长 ≤ 40 min，留 5 min 机动。

### 4.3 讲解设计（七步协议）★ 最值钱的一步
`references/explain-protocol.md`。七步：**现象 → 冲突 → 模型 → 命名 → 边界 → 迁移 → 反测**。

硬要求：
- **冲突**必须写出"学生最可能的错答"，并要求课件上**先出现错答再推翻**（不要直接给对的）。
- **边界**：这个模型什么时候不成立（例：酶不只降低活化能，还提供微环境/共价催化——高中层面要留一句"更完整的图景"）。
- **反测**：一道题，做对了说明懂了，做错了说明哪一步没接上。
- 判据 49 项，`check_kp.py`。

### 4.4 课件工程
见第 5 章。**这一章占了整套东西一半的工作量**，也是唯一"学生看得见"的部分。

### 4.5 习题检验
- 三层：**识记 / 迁移 / 反例**。反例题是分水岭（"下面哪个**不能**用…"）。
- 每题写**错因归类**（概念错 / 边界错 / 读题错 / 计算错），教师版才有价值。
- 至少 1 道"AI 会答错、学生该答对"的题（配合 4.6）。

### 4.6 AI 时代教学
三分类：**无 AI / AI 辅助 / AI 整合**。
写法：一句任务 + "为什么这一档" + "学生必须自己完成的那一步是什么"。
反模式：把"用 AI 查资料"当 AI 教学。

### 4.7 逐字稿
标三类记号：`【停】`（等学生）、`【板】`（写黑板）、`【追】`（追问）。
与课件逐页对齐；关键段优先于全稿（全稿 2600–3000 字/课时量级）。

### 4.8 视频演示（最后）
前七件任何一件不稳，视频都会把问题放大 10 倍。脚本先行（分镜 + 旁白 + 字幕时间轴），录制放最后。

### 4.9 审校交付
`check_kp.py` / `check_chapter.py` / `check_group.py` 三套 + 人工看预览页。

## 5 课件工程手册

### 5.1 管线（一条命令一层，每层可单独重跑）

```
内容 md ──┐
版式 plan.json ──┤ build_deck.py ──► SVG 页 ──► PPT Master 转换 ──► 原生 .pptx
                  │                        └─ 备注（讲稿）逐页写入
                  └─ 导出后自动串三件事：
                       ① polish_pptx.py   主题字体槽 + 图片替代文字
                       ② native_chart.py  画出来的曲线 → 原生图表
                       ③ animate_pptx.py  按块/按行/按句的进场动画
```

```sh
python3 scripts/build_deck.py --md "kp/…/06-课件.md" --plan "kp/…/06-课件.plan.json" \
  --out /tmp/deck-B --images assets/deck-images --theme classroom --tag=-B课堂
python3 scripts/animate_pptx.py /tmp/deck-B/06-课件-B课堂.pptx /tmp/deck-B/06-课件-B课堂-含动画.pptx
python3 scripts/make_preview.py --svg /tmp/deck-B/svg_output --out 预览/x.html --title … --theme …
```

**两条铁律**：
1. **改内容改 md，改样子改 plan.json**，重跑脚本；不要手改 pptx（下一轮会被覆盖）。
2. **字体、图表、动画都是"导出后"改的**——转换器只管几何，不管这些。

### 5.2 视觉系统：纸 + 墨 + 一个锈红

| 主题 | paper | ink | rust | ochre | panel | 用途 |
|---|---|---|---|---|---|---|
| plate 单墨 | `#F8F1E2` | `#1D2E29` | `#B8452A` | `#A9761F` | `#EDE6D6` | 印刷感、打印友好 |
| academic A | `#F1F0EB` | `#111E20` | `#9E2B1B` | `#8A6A2A` | `#E9E8E2` | 学术冷版，公开课 |
| classroom B | `#FAF3E3` | `#1A2A26` | `#B94E2A` | `#B5852B` | `#F2E6CB` | **课堂暖版（基准）** |
| textbook C | `#F7F4EA` | `#16282A` | `#A8432B` | `#9C7A2E` | `#F1ECDC` | 教材纸感 |

- B 版另设：ink2 `#5B6B5F`、rule `#E3D6BD`、teal `#2D6A54`、dark `#10201D`、**字号 scale 1.15**。
- **B 是认可基准**（"字体够大"）；不要为了"看起来精致"退回 A/C 的字号。
- 深色整版页上的强调色必须**提亮**（`on_dark()`）：A 版锈红 `#9E2B1B` 压在近黑底上只有 **2.5:1**，投影仪上一片糊 → 自动混纸色提到 `#AD4E40`。

### 5.3 版式库（12 种，按"这一页要干什么"选，不按好看选）

| layout | 干什么 | 铁律 |
|---|---|---|
| `cover` | 封面 | 一张图 + 一行题 + 一条手写线，别放目录 |
| `statement` | 一句话砸下来（"本课唯一的问题"） | 全页只有一个意思，字要大 |
| `plate_full` | 整版图 + 标题压暗部 | 图上必须叠 ≥0.6 的暗层，否则字看不清 |
| `plate_side` | 图文对开 | 图不裁切（meet），纸色与页面同色 |
| `diagram` | 原生矢量示意图（能量图、膜结构） | 用坐标画，不用贴图 |
| `chart` | 定量曲线 | **必须原生图表**（见 5.7） |
| `hero` | 一个巨大数字/符号 | 数字 ≥100px，其他全让路 |
| `compare` | 二选一对照 | 左右必须同构，别一边图一边字 |
| `table` | 三行以上结构化信息 | 隔行底色 + 行分隔线，行高 ≥40px |
| `checklist` | 错→对 的订正清单 | ✗ / → / ✓ 三色分工 |
| `quote` | 学生的话 / 教材原文 | 引号不装饰，靠字号和缩进 |
| `section` | 章节过场 | 深色整版 + 大号章节数字 |

### 5.4 配图：单墨版画（10 张，图内零文字）
- 统一画风：**单墨版画/铜版画**，纸色底、墨色线，不要照片、不要卡通、不要 3D。
- 每张出 `light` / `ink` 两个 duotone 版本（`scripts/duotone.py`），按页面底色挑。
- 图内**不许有文字**（文字要么在 SVG 里，要么没有）。
- 每张图必须有 `descr`（替代文字）——`polish_pptx.py` 只处理 `<p:pic>` 里的 `cNvPr`；
  **给所有 `cNvPr` 加 descr 会把形状、组合也标成"课程配图"**（实测一次 289 条垃圾）。

### 5.5 字体：PowerPoint 里改的是"主题槽"，不是 run
- 转换器把文字都写成 `+mj-lt` / `+mn-lt`（对的）。但 PPT Master 生成的主题
  **major 和 minor 都是 SimSun** → 预览里"标题宋体 + 正文黑体"，到 PowerPoint 里**塌成通篇宋体**。
- 必须用 `polish_pptx.py` 改主题槽：

| 槽 | 拉丁 | 东亚 |
|---|---|---|
| major（标题） | Times New Roman | 宋体 |
| minor（正文/表格） | Arial | 微软雅黑 |

- 交付前**必须有人在 PowerPoint 里看一眼**：标题衬线、正文无衬线。看不到差别 → 对方没走主题槽，改成硬写 `eastAsia`。

### 5.6 动画：按块不按字
`animate_pptx.py` 直接改 `ppt/slides/slideN.xml` 的 `<p:timing>`，**不动任何坐标**。

| 规则 | 说明 |
|---|---|
| 分块 | 按文档顺序 = 阅读顺序；纵向重叠的归一块 |
| 满版底图 | 永远第 0 块，随页面自动出现 |
| 首块 | 标题自动；封面/收尾页整体自动（不进点击序列） |
| 逐行/逐句 | 块内若有**同左边缘、等距堆叠的短文本 ≥3 条**（列表/表格），一条一步；图不拆（判据见 `list_rows()`） |
| 上限 | 常规 ≤6 块；允许拆分时 ≤9 块；超了合并最短的相邻块 |
| 页脚 | 并进最后一块（不要"点一下才出页码"） |
| 效果 | 整块 `fade`；宽扁块（高 ≤150px 且宽 ≥620px，如表格行/通栏）`wipe(up)` |

**presetID 必须配对**（写错不报错、能播，但动画窗格标错）：

| 名 | filter | presetID | 方向 | 时长 |
|---|---|---|---|---|
| fade | `fade` | **9**（10 是 dissolve） | — | 500ms |
| wipe | `wipe(up)` | 22 | 1 | 420ms |
| reveal | `wipe(left)` | 22 | 8 | 460ms |

死路径（解析通过、播放静默丢弃，别用）：`p:anim` 打在 `fill.opacity` / `stroke.weight` / `stroke.opacity` 上。
`p:animEffect` 必须与 `p:set style.visibility` 配对。

### 5.7 原生图表：别交"能看不能改"的图
曲线用 SVG 画出来，到 PPT 里是一条 Freeform——改一个数据点要重画整张。
`build_deck.py` 画图时把采样点写进 `<stem>-charts.json`；`native_chart.py` 删掉那块画出来的图，在同一位置插 `XY_SCATTER_SMOOTH_NO_MARKERS`：

- 坐标轴标题、图例、网格线、系列颜色/虚线全部原生；
- 刻度数字**隐藏**（示意图，0–1 归一化，写具体数值是假数据）；
- 图表放进 `content` 组，所以动画照样能引用它；
- 交付话术："右键 → 编辑数据，把两列换成实测值就行。"

### 5.8 备注（讲稿）
md 里 `<!-- note -->` → pptx 每页备注，条数与 md 一致（酶 15/15、第4章 24/24）。
备注写"老师要说的那句话"，不是写"本页讲什么"。

| 知识点 | `check_kp.py <kp 目录>` | PASS 49 / WARN 0 / FAIL 0 |
| 单章 | `check_chapter.py <章目录>` | PASS 36 / WARN 0 / FAIL 0 |

| 动画 | `animate_pptx.py` 自检 | 每页 id 不重复、`spTgt` 全命中、步数合理 |

**两道自测存在的理由**：一道门如果永远返回 0，它就是摆设。合成用例必须能证明它抓得到问题

**校准值**（改了就重跑全部 8 套）：
`merge_text_runs` 行距系数 **2.05**、`check_overflow` 行距 **1.05**、聚类 `gap=24 / min_h=22`、
`pick_effect` 阈值 `h≤150 & w≥620`、对比度 `4.2 / 3.0`。

## 7 踩坑清单

| 症状 | 原因 | 做法 |
|---|---|---|
| 预览好看，PowerPoint 里正文全变宋体 | 主题 major/minor 都是 SimSun | `polish_pptx.py` 改主题槽 |
| 动画窗格标的不是"淡入" | `presetID=10` 是 dissolve | fade 用 **9** |
| 表格点一下整张出来 | 行被聚成一块 | `list_rows()` 逐行；或确认行间有分隔线 |
| 一张图被拆成十几步 | 按 y 带硬拆 | 只拆"同左边缘等值堆叠 ≥3 条的文本列" |
| 图片替代文字 289 条 | 对所有 `cNvPr` 加 descr | 只处理 `<p:pic>` 内的 |
| 曲线改不了 | SVG 路径对象 | `native_chart.py` 换原生图表 |
| 深色页强调色发闷 | 对比度 <3:1 | `on_dark()` 自动混纸色提亮 |
| 手写装饰线切到字顶 | 线画在 `y-16`（正好是字冠高度） | 抬到 `y-32`；`check_shapes` 会报"线穿字" |
| `--tag -A学术` 报参数错 | 以 `-` 开头的值被当选项 | 写 `--tag=-A学术` |
| 预览换地方打开一片白 | 引用了相对路径的 SVG | `make_preview.py` 单文件内联 |
| 端口被占 | 8000 常被沙箱占用 | 用 8099 |
| Word/PPT 里中文缺字 | 沙箱没中文字体 | 判"几何合规"，字形靠人看预览 |

## 8 反模式（见到就停）

1. **先做课件再写教案**：课件会变成"教材要点罗列"，讲不出冲突。
2. **一页放三个意思**：学生一次只接得住一个。
3. **拿照片当示意图**：照片有背景噪声，示意图只该有该有的线。
4. **动画按字飞入**：花哨、打断思维；按块/按行才对。
5. **用 AI 生成"教学设计"直接交付**：没有冲突设计的目标链，是漂亮废话。
6. **只交 pptx 不交预览**：别人打不开 = 没交付。
7. **在 pptx 上手工改版**：下一轮脚本一跑全没了。

## 10 已知没做的

- **图形元素相撞**只覆盖"覆盖/穿行/越界"三类，斜向箭头与曲线围出的封闭区域的语义冲突判不了。
- **原生图表**目前只接"曲线型"（XY 散点）；柱状/饼图未接。
- **动画**没有做"强调"（emphasis）与"退出"（exit），只有进场。
- **视频**只有脚本，没有成片（沙箱无 ffmpeg/无中文字体）。
- **字体**依赖 PowerPoint 走主题槽；WPS 老版本可能不吃，需要在目标机器上实看一次。
