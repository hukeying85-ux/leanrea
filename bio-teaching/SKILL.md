# bio-teaching：一章教材 → 一套能上课的资产

**核心原则：一章一对话，一模块一产物，一产物一 gate。**
不要一口气做完 5 章，也不要在一份文档里同时写教案、课件和逐字稿——它们的读者不同（教师备课 / 学生在课堂看 / 教师张嘴说），混在一起三边都写不好。

**第二原则：备课的功夫在"学生已经怎么想"上。**
教材写的是结论，课堂要处理的是学生脑子里已有的错误结论。每章先写 5–6 条迷思概念（misconception），后面所有模块都围着它们转：教案设计冲突、课件放反例、习题专打这些点、AI 活动让学生自己撞一次。

## 何时用 / 何时别用

- 用：要备一课/一章并交付教案、课件、习题；要把教材转成可复用教学资产；要做公开课/说课材料；要设计 AI 融合的教学活动。
- 别用：只想要一段知识讲解（直接讲即可）；要整册学期课程规划（先出 `references/chapter-map.md` 的全册骨架，再逐章跑）；要出正式考试卷（走题库/命题规范，本模块的习题只做教学检验）。

## 流水线（8 个模块，按顺序，可中断可续）

```
00 教材拆解 → 01 章节任务规划 → 02 教学设计 → 03 课件 → 04 习题
                                      ↘ 05 AI 时代教学 ↗
                              06 逐字稿 → 07 视频演示 → 08 审校交付
```

每个模块对应 `prompts/` 下一条对话，产物落到 `chapters/<册>/<章>/`：

| # | 模块 | 产物 | 读者 | 关键 gate |
|---|---|---|---|---|
| 00 | 教材拆解 | `01-教材拆解.md` | Agent + 教师 | 概念层级到"次位概念"；≥5 条迷思带证据；每个命题点能指回教材栏目 |
| 01 | 任务规划 | 写进 `02-教学设计.md` 头部 | 教师 | 课时数 × 45min 时间预算守恒；每个任务有动词型目标 |
| 02 | 教学设计 | `02-教学设计.md` | 教师 | ABCD 目标 + 问题链 + 每个活动有"学生产出物" + 评价证据对齐目标 |
| 03 | 课件 | `03-课件.md` + `.pptx` | 学生 | 1 页 1 个认知动作；标题是结论不是名词；无整段教材原文 |
| 04 | 习题 | `04-习题检验.md` | 学生/教师 | 三层（基础/应用/迁移）；每题标迷思编号与错因；答案与解析分离 |
| 05 | AI 时代 | `05-AI时代教学.md` | 教师 | 每个 AI 活动写清"AI 做什么 / 学生判断什么 / 没有 AI 怎么替代" |
| 06 | 逐字稿 | `06-逐字稿.md` | 教师 | 口语不是书面语；标 `[停]` `[板书]` `[追问]`；每 5 分钟一个互动点 |
| 07 | 视频演示 | `07-视频演示.md` | 制作 | 分镜表（时间/画面/旁白/字幕）；给出可跑的 ffmpeg 或 manim 路线 |
| 08 | 审校 | `index.md` 交接单 | 全链 | `check_chapter.py` 全 PASS；事实核验表；版权与 AI 声明 |

## 规则

- **教材不进仓库。** 只写自己产出的拆解，引用标"册-章-节-栏目"（如"必修1 第1章 第1节 思考·讨论"）。不抄原文段落、不存 PDF。
- **概念层级只写到次位概念。** 课标大概念 → 重要概念 → 次位概念（例：概念1 → 1.1 细胞学说 → "细胞是一个相对独立的单位"）。再往下是课堂事实，不占目标层级。
- **目标动词必须可观察。** "理解细胞学说"不合格；"能用三条证据说明细胞学说的三个要点，并指出它的局限"合格。
- **时间预算守恒。** 45 分钟里，讲授 : 学生活动 : 评价 ≈ 4 : 4 : 2，新增任何环节必须从别处显性扣减。
- **每页课件只推进一步。** 一页同时出现"概念 + 例子 + 数据 + 提问"＝拆成三页。
- **AI 是对象也是工具。** 既教"AI 能做什么"（图像识别、概念图、批改），也教"AI 会错在哪"（幻觉、貌似合理的因果）。AI 活动必须有"没有 AI 也能做"的对照版。
- **证据优先。** 教学效果、学生表现、成绩数据不得编造；没有真实课堂数据就写"待实测"。
- **一章一回合。** 08 通过后就停下，报告状态，等总控派下一章。不主动跨章写。

## 质量门（下一条对话开始前必须过）

1. 目标—活动—评价三者一一对应（表格化，缺一列即不合格）。
2. 每节课至少有 1 次"认知冲突"（学生原以为 A，证据指向 B）。
3. 课件页数 ≈ 课时数 × 8–10；正文每页 ≤ 45 字（不含图表标注）。
4. 习题覆盖本层全部迷思；表现为"选错选项能诊断出哪条迷思"。
5. AI 部分不能只有"用 AI 生成 X"，必须有判断与核验环节。
6. 逐字稿朗读时长 ≈ 课时 × 0.55（留出活动与停顿）。
7. 视频分镜单条 ≤ 3 分钟，字幕与旁白逐句对齐。
8. `python3 scripts/check_chapter.py <章目录>` 无 FAIL。

## 反模式（都踩过）

| 现象 | 原因 | 修法 |
|---|---|---|
| 教案写了 3000 字，上课 10 分钟就讲完 | 写的是"教的内容"不是"学生的动作" | 每个环节只写：学生做什么 → 产出什么 → 你怎么知道他会了 |
| 课件是教材的截图搬运 | 把"覆盖内容"当教学目标 | 一页一个认知动作；教材段落一律转成图/表/问题 |
| 习题全是记忆题 | 顺着教材顺序出题 | 先按迷思定考点，再倒推题干 |
| AI 环节变成"让 AI 写总结" | 没有不可替代的学生动作 | 改成"AI 给答案 → 学生找证据反驳/验证" |
| 逐字稿像论文 | 写给人看不是给人说 | 一句 ≤ 25 字；把"因此/综上所述"换成"所以/你看" |
| 一章写了两周还没完 | 想一次做完美 | 先出"能用版"（每模块 1 页），过 gate 后再迭代深挖 |
| 视频拖到最后做不出来 | 依赖 manim/TTS 环境 | 默认走"图片 + 旁白 + ffmpeg"最低成本路线，manim 只做加分项 |

## 交付语言

默认简体中文，学科术语用教材用词（"原核细胞"不写"原核生物细胞"；"细胞学说"不写"细胞理论"）。
面向学生的一律用"你"，面向教师的一律用"你"或省略主语，不用"我们应当"。
