# 第4章 成组：4 个知识点怎么排成 3 课时

> 人教版（2019）必修1 第4章「细胞的物质输入和输出」｜3 课时｜高一上
> 这一份是**成组件**，不替代任何单课时教案。它只回答一个问题：**这 3 节课凭什么是一章，而不是 3 个孤立的知识点。**
> 单知识点完整集见 `bio-teaching/kp/`（主动运输已是 11 份完整集）。

## 一、一条主线（全章只用一个情境）

**盐碱地里的一株海水稻。**

不是"举例"，是**贯穿**：3 节课的每一个任务，都回到这株植物的根细胞。

```
                     一株海水稻的根细胞
                            │
   ① 水怎么进来 ──────── 渗透作用（课时1）       土壤溶液浓度高，水反而被"抢"
                            │
   ② 水/气怎么过膜 ───── 自由扩散（课时2）       不用载体，不花钱
                            │
   ③ 葡萄糖怎么进来 ──── 协助扩散（课时2）       要载体，不花钱
                            │
   ④ K⁺ 怎么逆浓度进来 ─ 主动运输（课时3）       花 ATP，把 Na⁺ 赶出去 → 耐盐
                            │
   ⑤ 大分子怎么进出 ──── 胞吞胞吐（课时3）       不跨膜，靠膜的流动性
```

主线的好处很实在：**"为什么值得花这个钱"这件事，第 3 课时不用再论证**——学生从第 1 课时就看着这株稻子在盐里活着。

## 二、四个知识点 → 三课时（切分口径）

| 课时 | 承载的知识点 | 主问题 | 学生要带走的一个工具 |
|---|---|---|---|
| 1 | 渗透作用（C4.1-01）、质壁分离（C4.1-02） | 水为什么会往"浓"的一边跑？ | **水势箭头**：水从"水多"流向"水少" |
| 2 | 自由扩散（C4.1-03）、协助扩散（C4.1-04） | 不花钱的两种过膜方式，差在哪？ | **三条判据的第 1、2 栏**：方向、载体 |
| 3 | 主动运输（C4.2-01）、胞吞胞吐（C4.2-02） | 逆着浓度走，凭什么？ | **三栏判定表补全**：方向 / 载体 / 能量 |

切分理由：**按"判据的栏数"切，不按教材页数切。** 课时 1 只用到"方向"，课时 2 加上"载体"，课时 3 加上"能量"。学生的判定工具是一栏一栏长出来的，不是最后一节课一次性塞进去的。

## 三、一张表走三节（黑板右下角，从不擦）

| | 方向 | 载体 | 能量 | 水 | 葡萄糖（红细胞） | K⁺（根细胞） |
|---|---|---|---|---|---|---|
| 自由扩散 | 顺 | 无 | 不耗 | ✓ | | |
| 协助扩散 | 顺 | 有 | 不耗 | （水通道） | ✓ | |
| 主动运输 | 逆 | 有 | 耗 ATP | | | ✓ |
| 胞吞胞吐 | — | 无（靠膜流动） | 耗 | | | （大分子） |

**用法**：课时 1 只画"方向"一列；课时 2 加"载体"一列；课时 3 加"能量"一列。**每节课都在旧表上加一列，学生看到的是同一张表在长。**

这一条是本章成组的技术核心。三节课各画一张新表的做法，看起来更整齐，实际让学生背了三遍互不相干的表。

## 四、跨课时的四个钩子（每次 1 分钟，不占正课）

| # | 在第几课时末尾埋 | 说什么 | 在哪一课时回收 |
|---|---|---|---|
| 钩 1 | 课时 1 末 | "水能自由进出，那土里的 K⁺ 为什么进不来？" | 课时 3 开场（一句话回收，不重讲） |
| 钩 2 | 课时 2 末 | "协助扩散有载体、不花钱。可细胞里的 K⁺ 比外面多 28 倍，载体也没用，差什么？" | 课时 3 冲突 A |
| 钩 3 | 课时 3 中段 | "Na⁺ 被赶到细胞外，可外面 Na⁺ 更多，怎么赶得动？" | 课时 3 尾（回扣海水稻耐盐机制） |
| 钩 4 | 课时 3 末 | "大分子不跨膜也能进出——那膜还叫'屏障'吗？" | 选择性必修 1（免疫、分泌蛋白） |

**钩子必须回收**。埋了不回收，学生会认为那只是老师的一句闲话。本章的 4 个钩子全部在 3 课时内闭环。

## 五、不重复的检查（成组最容易犯的错）

写完 3 课时后，用这张表自查——**同一个内容只准在两处出现：讲一次、用一次。**

| 内容 | 讲在哪 | 用在哪 | 判定 |
|---|---|---|---|
| 渗透作用的条件 | 课时 1 | 课时 2 判"水是自由扩散还是有通道" | 讲一次，用一次 ✓ |
| 载体蛋白的特异性 | 课时 2 | 课时 3 讲主动运输时直接用 | 讲一次，用一次 ✓ |
| ATP 供能 | 第 3 章（前置） | 课时 3 | 前置知识，只提不重讲 ✓ |
| 细胞膜的流动镶嵌模型 | 第 3 章（前置） | 课时 2（载体）、课时 3（胞吞胞吐） | 前置知识，用两次 ✓ |
| 质壁分离实验 | 课时 1 | 课时 1 实验 + 课时 3 习题 | 讲一次，用两次 ⚠ 可接受，注意别在课时 3 重讲原理 |

最后一行是本章唯一的重复风险点：习题里出现质壁分离，**只判"细胞是死是活、是吸水还是失水"，不重讲原生质层**。

## 六、三课时的讲授比例（防止三节课都变成讲授）

| 课时 | 讲 | 练 | 收 | 说明 |
|---|---|---|---|---|
| 1 | 16 | 19 | 5 | 实验课，学生动手为主 |
| 2 | 22 | 13 | 5 | 曲线与判据，讲得最多 |
| 3 | 18 | 17 | 5 | 讨论最多，与 `kp/必修1-第4章-主动运输` 一致 |

三节课平均讲授 46%，比单课时"讲 70%"的老上法低一档。第 2 课时是唯一超过 20 分钟的，因为"载体 vs 通道"必须讲清，否则第 3 课时讲不动。
