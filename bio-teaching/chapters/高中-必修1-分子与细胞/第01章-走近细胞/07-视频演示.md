## 2. 旁白全文（可直接给 TTS）

```
1665 年，一块软木塞。
他看到了很多小格子，叫它们 cell。
可这些格子，早就死了。
一百多年后，另一个人看到了活的。
施莱登看植物，施旺看动物。他们说了同一句话。
那细胞从哪来？魏尔肖：老细胞分裂。
三句话，三个人，攒了 170 年。
但病毒没有细胞。所以是"除病毒外"。
```

后处理：句间停顿 300–500 ms；"死了""除病毒外"后各加 600 ms（配合画面变灰与红线）。

## 3. 制作路线 A：图文 + 旁白 + ffmpeg（推荐，当天可出）

```sh
mkdir -p shots voice out

# 1) 8 张画面：1920×1080 PNG，按分镜编号 01.png … 08.png
#    最低成本做法：PowerPoint 做 8 页，导出 PDF 再转 PNG
#    pdftoppm -png -r 150 deck.pdf shots/p

# 2) 8 段旁白：手机录音或 TTS，导出 01.mp3 … 08.mp3
#    用 ffprobe 读时长，决定每段视频长度（先音后画）

# 3) 单幕合成（每幕：静态图 + 缓推 + 该幕旁白）
for i in 01 02 03 04 05 06 07 08; do
  D=$(ffprobe -v error -show_entries format=duration -of csv=p=0 "voice/$i.mp3")
  F=$(python3 -c "print(int($D*30)+15)")        # 30fps，尾部留半秒
  ffmpeg -y -loop 1 -i "shots/$i.png" -i "voice/$i.mp3" \
    -filter_complex "[0:v]scale=2400:-1,zoompan=z='min(zoom+0.0006,1.05)':d=$F:s=1920x1080:fps=30,format=yuv420p[v]" \
    -map "[v]" -map 1:a -c:v libx264 -crf 20 -preset medium -c:a aac -b:a 128k -shortest "out/seg$i.mp4"
done

# 4) 拼接
printf "file 'seg01.mp4'\nfile 'seg02.mp4'\nfile 'seg03.mp4'\nfile 'seg04.mp4'\nfile 'seg05.mp4'\nfile 'seg06.mp4'\nfile 'seg07.mp4'\nfile 'seg08.mp4'\n" > out/list.txt
ffmpeg -y -f concat -safe 0 -i out/list.txt -c copy out/cell-theory.mp4

# 5) 烧字幕（SRT 按分镜时间码写，最多 12 字/行）
ffmpeg -y -i out/cell-theory.mp4 -vf "subtitles=subs.srt:force_style='FontName=Noto Sans CJK SC,FontSize=22,Outline=1'" \
  -c:a copy out/cell-theory-subbed.mp4
```

注意：
- `zoompan` 的 `d` 必须等于"该幕时长 × fps"，否则末帧会跳。上例用 `ffprobe` 读旁白时长再算。
- 8 幕编码参数必须一致，否则 `-c copy` 拼接会失败。
- 中文字幕需要 CJK 字体（`fonts-noto-cjk`），否则烧出来是方框。

## 4. 制作路线 B：Manim（只有需要"真过程"时才用）

本片第 6 幕（细胞分裂）与第 5 幕（网格生成）适合 Manim，其余用静态图更省时。

```sh
sudo apt install -y ffmpeg libcairo2-dev libpango1.0-dev fonts-noto-cjk
python3 -m pip install manim
manim -pqh scene.py CellTheory -o cell-theory.mp4
```

分镜与代码对应：一幕 = 一个 `Scene` 或一组 `self.play`；旁白触发词处插 `self.wait(0.6)`，后期用时间戳对齐音轨。
**旁白先录，动画后配**——反过来必然出现"话已说完，图还没动"。
