# 04 · 习题检验（把迷思变成选项）

**独立对话。** 输入 `01-教材拆解.md`（概念 + 迷思编号）+ `02-教学设计.md`（目标）。产出 `04-习题检验.md`（教师版）与 `04-习题-学生版.md`。

## 出题逻辑：先定"打哪条迷思"，再写题干

顺序永远是：**目标 → 迷思 → 考点 → 题干 → 选项（错项 = 迷思）**。
反过来做（先想一个好玩的题）就会出现"题很好看，但诊断不出任何东西"。

## 三层配比

| 层 | 占比 | 特征 | 典型问法 |
|---|---|---|---|
| 基础 | 40% | 单一概念，术语准确性 | 判断、填空、识图标注 |
| 应用 | 40% | 新情境里用概念 | 给材料/图表，解释现象 |
| 迁移 | 20% | 跨概念、跨章、真实问题 | 论证、实验设计、数据分析 |

## 每题的必备标注

```markdown
### 5. [应用][C1.2-02][M4]
关于蓝细菌的叙述，正确的是（  ）
A. 没有细胞器，不能进行光合作用      ← M4（认为无细胞器=不能光合）
B. 含有藻蓝素和叶绿素，能进行光合作用  ← 正确
C. 有叶绿体，但没有核膜                ← M4 变体（原核有叶绿体）
D. 属于真核生物                        ← M1（缺少核膜判断）
> 答案 B　解析：…（说明 A/C/D 各对应哪条迷思，学生在哪一步想错）
> 变式：换成"发菜""水华"情境，考点不变
```

## 题型配方（一章 10–14 题）

| 题型 | 数量 | 要求 |
|---|---|---|
| 选择 | 5–6 | 4 个选项；错项各自对应不同迷思，不要三个"明显不对" |
| 填空/识图 | 2–3 | 图必须自绘或授权；标号 ≤8 个 |
| 简答（论证） | 2 | 要求"观点 + 证据 + 推理"，给评分点 |
| 实验/探究分析 | 1–2 | 变量、对照、结论边界各设一问 |
| 开放/迁移 | 1 | 真实情境（本地物种、公共卫生、AI 工具），给评分量规 |

## 解析的写法

一道题的解析四句话，缺一句就是没写透：

1. **考点**：这道题在考哪条概念（编号）。
2. **正解**：为什么对（不是重复选项）。
3. **错因**：每个错项背后学生怎么想的。
4. **变式**：换一个情境还能考同一考点。

## 学生版

- 去掉答案、解析、迷思标注、教师提示。
- 保留题号与分值。
- 末尾加一行：`本章重点概念：C1.1-01 … C1.2-04（编号见讲义）`。

## 真实题目怎么办

- 引用真题必须标**年份 + 地区 + 卷别**；改编标"改编自…"。
- 拿不到可靠来源就自己写，但**不要声称是某年真题**。
- 想核对本层真实难度，可对接题库类 skill（如 `tizhuang-agent-skills`）抽同章节真题对照，但不要把它的题直接搬进产物（版权与答案口径不受控）。

## 交付前自检

- [ ] 每题的迷思标注都能在拆解表里找到对应编号
- [ ] 错项不是"凑数"：任意两个错项对应不同想法
- [ ] 三层题量比例符合 4:4:2（±1 题）
- [ ] 学生版不含任何答案痕迹
- [ ] 至少 1 题要求学生用本课证据反驳一个错误说法
