# 02b · 讲解设计（一个知识点，怎么讲才懂）

**独立对话。** 输入：一个知识点（一句话）+ 学段 + 学生已学。产出：`00-讲解设计.md`。
这是**粒度最细的一层**：一章下面按知识点做，一个知识点 20–40 分钟。方法见 `references/explain-protocol.md`（七步协议）。

## 什么时候必须做这一步

- PPT 做出来但"像教材搬运" → 缺的就是这一步
- 学生上课点头、作业全错 → 坎没找对
- 同一知识点讲了三遍还有人错 → 类比撑不住变式
- 要做视频/微课 → 分镜的骨架就是这一份

## 输入（三行就够）

```
知识点：氨基酸的脱水缩合与蛋白质结构多样性（必修1 第2章 第4节）
学段：高一上，已学"蛋白质的功能""氨基酸的结构通式"
约束：40 分钟，学生基础中等，无实验条件
```

**不需要教材全文**。需要的是：机制本身、课标要求的深度边界、以及学生通常错在哪。教材只用来核口径（术语、符号、讲到哪里为止）。

## 步骤

**1 定靶**：写 3–4 条可观察行为（能画 / 能算 / 能解释 / 能判断），不写"理解"。

**2 找坎**：3–6 条迷思，每条三栏：`他会怎么说` / `错在哪` / `什么题能钓出来`。

**3 造冲突**：设计一个 30 s–2 min 的小任务，用旧想法必然答错。写清"学生大概会答什么""正确答案是什么""他为什么会愣一下"。

**4 给具象**：选一个类比，写清三件事——`怎么用手比/怎么画`、`类比里能数的是什么`、`它哪里不像真实机制`。

**5 命名压缩**：现象→矛盾→机制→名称的顺序写一遍；最后给出**一句定义**（≤25 字）和 1–3 个符号。

**6 走变式**：3 个变式，每次只变一个维度；每个变式写"公式/结论怎么变""学生会在哪卡住"。
**公式不先给**，用"数接缝"的方式推出来。

**7 回收复述**：三个动作（同伴复述 30 s、一句边界、回到用处），各写一句你要说的话。

## 禁止

- 不写"通过讲解使学生理解…"。写行为。
- 不把教材定义抄成"机制"。
- 不换类比。一个撑不住就重选，别叠加。
- 不在这一步写课件页数、教学目标 ABCD（那是 02）、不写习题（那是 04）。

## 自检

- [ ] 冲突任务能在 2 分钟内做完，且旧想法必错
- [ ] 类比写明了"哪里不像"
- [ ] 公式是"数出来"的，不是"给出来"的
- [ ] 3 个变式各只变一个维度
- [ ] 有一句 ≤25 字的定义
- [ ] 时间预算含 15 分钟练习
