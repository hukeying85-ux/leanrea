# 06 · 课堂逐字稿

**独立对话。** 输入 `02-教学设计.md`（环节表）+ `03-课件.md`（页码）。产出 `06-逐字稿.md`。
读者是**要张嘴的那位老师**。它必须能被读出来，且读出来像人说话。

## 三条硬规则

1. **单句 ≤25 字。** 超过就拆。书面语的因果链（"由于…因此…进而…"）在口头会断。
2. **一句话只说一件事。** 说完一件事，给一个停顿。
3. **每 5 分钟一个互动。** 提问、举手、同桌说、看屏幕数一数、写一行——都算。

禁用词表：综上所述 / 鉴于此 / 众所周知 / 毋庸置疑 / 显而易见 / 值得注意的是 / 我们可以看到。
替换建议：所以 / 你看 / 大家想想 / 注意这里 / 停一下。

## 标记系统

| 标记 | 含义 |
|---|---|
| `[停 3s]` | 停顿，等学生反应 |
| `[板书：…]` | 写板书的动作与内容 |
| `[看第 7 页]` | 切课件 |
| `[追问]` | 学生答完后追加一问（写清追问什么） |
| `[走动]` | 走到某组/某区域 |
| `[低声]` | 降音量，用于制造注意 |
| `[举手统计]` | 快速了解分布 |

## 结构（与教案环节一一对应，不要自创顺序）

```markdown
# 第1章 走近细胞 · 课时 1 逐字稿
> 45 min | 课件 18 页 | 对应 02-教学设计 环节表

## 0. 上课前 30 秒（不写进正文，但要说）
"把课件翻到第 1 页的同学先看一眼这张图，先别说话。"

## 1. 导入（5 min｜课件 P1–P2）
（略去寒暄，直接进入）
"先看这张图。1665 年，一个人把软木塞切得薄薄的，放在自己做的显微镜下。[停 3s]
他看到了很多小格子。[停 2s]
他给这些小格子起了个名字，叫 cell——小房间。
现在问题来了：他看到的是活的，还是死的？[举手统计]
——两种都有人举手，很好。我们先不急着定。"

## 2. 任务一（12 min｜课件 P3–P6）
...
```

## 关键位置的写法

**提问后必须写"接住答案"的三条分支**（至少两条）：

```
[追问] 你说"是活的"，依据是什么？
  ├ 学生说"会动" → "那显微镜下的水分子也在动，它算活的吗？"（引出"生命特征"）
  ├ 学生说"有结构" → "好，那我们看看这张图里有没有细胞核。"（引向细胞壁 vs 细胞）
  └ 没人答 → "我换个问法：如果它是死的，它原来活着的时候是什么样？"
```

**难点处写"降台阶"**：从具体到抽象给三级台阶，逐级写在稿子里。

**结尾不要总结陈词**，回到主问题，让学生自己说：

```
"今天我们看了三个人、一张图、一个学说。[停]
回到开头那个问题：为什么说细胞是生命活动的基本单位？[停 5s]
不用完整，说一个词也行。"
```

## 时长核算

朗读字数 ≈ 时长 × 0.55 × 220 ≈ **每分钟 120 字有效口播**（其余是活动与停顿）。
45 分钟课时 ≈ 5000–5400 字，其中师生活动段只写"教师话术 + 预判答案"，不写学生台词。
