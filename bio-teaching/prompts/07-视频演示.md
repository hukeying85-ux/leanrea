## 分镜表（唯一核心产物）

| 时间 | 画面 | 旁白（说到哪个词触发） | 字幕 | 动效/转场 |
|---|---|---|---|---|
| 0:00–0:08 | 软木塞纹理特写，缓慢推近 | "1665 年，一块软木塞。" | 1665 · 软木塞 | 推近 |
| 0:08–0:20 | 小格子逐个亮起 | "他看到了很多小房间，于是叫它 cell。" | cell = 小房间 | 逐个高亮，同步"小房间" |
| 0:20–0:32 | 切换为活细胞显微图 | "可这些格子，早就死了。" | 死细胞壁 ≠ 活细胞 | 交叉溶解 |

规则：
- **旁白先写，画面后配。** 顺序反了就会出现"画面很美，话说不清"。
- 每个动画触发点绑一个**旁白关键词**（说到"核膜"才画核膜）。这是 MathLens 的 `wait_for_narration` 思路。
- 单条 ≤3 min；概念片 60–120 s 最合适。
- 字幕与旁白逐句一致，不写"意译版"。

## 两条实现路线（先低后高）

### 路线 A：图文 + 旁白 + ffmpeg（最低成本，默认走这条）

```sh
# 1) 每幕做一张 1920×1080 图（自绘/PowerPoint 导出/程序绘制均可）
#    命名 01.png 02.png …，放进 shots/
# 2) 录旁白：手机录音或 TTS，按幕切成 01.mp3 02.mp3
# 3) 单幕合成（以第 1 幕 8 秒为例）
ffmpeg -loop 1 -i shots/01.png -i voice/01.mp3 \
  -filter_complex "[0:v]scale=2304:-1,zoompan=z='min(zoom+0.0008,1.06)':d=240:s=1920x1080:fps=30[v]" \
  -map "[v]" -map 1:a -c:v libx264 -crf 20 -c:a aac -shortest seg01.mp4
# 4) 拼接（各段编码参数一致）
printf "file 'seg01.mp4'\nfile 'seg02.mp4'\n" > list.txt && ffmpeg -f concat -safe 0 -i list.txt -c copy out.mp4
# 5) 烧字幕（可选）
ffmpeg -i out.mp4 -vf "subtitles=subs.srt" -c:a copy final.mp4
```

注意：`zoompan` 的 `d` 要与时长×fps 对齐，否则末帧会跳。旁白时长决定幕长，先音后画。

### 路线 B：Manim（加分项，概念有"过程"时才用）

适合：细胞分裂、物质运输、神经冲动传导、光合作用流程、遗传概率。
不适合：分类、名词、结构名称记忆（用静态图更快）。

```sh
# 装环境（Linux）
sudo apt install -y ffmpeg libcairo2-dev libpango1.0-dev fonts-noto-cjk
python3 -m pip install manim
manim -pqh scene.py CellTheory -o cell_theory.mp4
```

分镜与代码的对应关系：一幕一个 `Scene` 或一个 `self.play` 组；旁白关键词处插 `self.wait()`，后期按时间戳对齐音轨。

## 生物学科的分镜原型（可直接套）

| 原型 | 用在哪 | 画面套路 |
|---|---|---|
| 尺度推拉 | 细胞大小、DNA 长度、进化时间 | 一条对数刻度尺，镜头从人体推到细胞器 |
| 过程分解 | 分裂、运输、光合 | 同一构图，分 3–5 步叠加箭头与标注 |
| 对比并置 | 原核/真核、动脉/静脉 | 左右分屏，同一图层逐项点亮差异 |
| 史料时间线 | 细胞学说、DNA 双螺旋 | 竖排时间轴，卡片逐张落下，错误说法变红划掉 |
| 数据动画 | 种群增长、酶活性曲线 | 坐标系先画，点逐个出现，曲线跟随 |
