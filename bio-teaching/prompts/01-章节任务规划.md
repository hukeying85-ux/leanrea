# 01 · 章节任务规划（一章 → 课时 → 任务）

**独立对话。** 输入 `01-教材拆解.md`，产出写进 `02-教学设计.md` 的头部（课时表 + 任务清单 + 时间预算）。
这一步决定了后面所有模块的骨架，做错了两周才发现。

## 判断课时数

| 信号 | 加课时 | 减课时 |
|---|---|---|
| 次位概念 >5 条 | +1 | |
| 有"探究·实践" | +1（实验课单独算） | |
| 有 ≥2 条迷思需要正面冲突 | +1 | |
| 概念与学生日常经验距离远（分子、电位、进化时间尺度） | +1 | |
| 纯事实记忆型内容 | | −1（并入前后课时） |
| 与上游章重复表述 | | −1 |

铁律：**总课时先定，再往里塞内容。** 不允许"内容太多所以加一课时"（课时是学校的，不是你的）。

## 时间预算（每 45 min）

```
导入 5'        任务一 12'     任务二 15'     任务三 8'     评价与小结 5'
```
- 讲授 : 学生活动 : 评价 ≈ 4 : 4 : 2。
- 任何新增环节必须从上面某一段显性扣减，并在表里写出"从哪扣"。
- 实验课另算：安全与操作说明 8' + 操作 25' + 记录与汇报 10' + 清理 2'。

## 任务设计模板

每个任务只写三件事：

```markdown
### 任务一 用史料卡重建细胞学说（12 min）
- 学生做什么：6 张史料卡排序，圈出每张卡"新观察到的证据"
- 产出什么：一张时间轴 + 一句话总结（谁、看到什么、推出什么）
- 怎么知道他会了：抽 2 组说"你为什么把魏尔肖放最后"
```

**不要写"教师讲解细胞学说的建立过程"。** 那不是一个任务，是一段独白。
