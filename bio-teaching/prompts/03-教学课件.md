# 03 · 教学课件（md 大纲 → .pptx + HTML 预览）

**独立对话。** 输入 `02-教学设计.md`，产出 `03-课件.md` + `03-课件.plan.json`（版式层），再跑 `scripts/build_deck.py` 生成三版 pptx。
课件是给**学生在课堂上看**的，不是给教师看的讲义，也不是教材的投影版。

## 一条铁律

**每一页只推进一个认知动作。** 十种页型，选一种，别混：

| 页型 | 用途 | 例 |
|---|---|---|
| 封面 | 课题 + 一句悬念 | "300 年前，他以为自己看到了'小房间'" |
| 情境 | 真实照片/新闻/现象 | 显微镜下的四种细胞 |
| 概念 | 立一个概念，配一张图 | 细胞学说的三个要点 |
| 对比 | 两栏对照 | 原核细胞 vs 真核细胞 |
| 反例（必做 ≥1） | 打破迷思 | "所有生物都由细胞构成？——那它算什么" |
| 层次图 | 结构/流程/尺度 | 细胞→组织→器官→系统→个体 |
| 任务 | 学生要做什么 + 时间 | "6 张卡，3 分钟，排出先后" |
| 数据/证据 | 一个数字或一张表 | 放大倍数与视野细胞数的关系 |
| 小结 | 回到主问题 | "所以，为什么说细胞是基本单位" |
| 作业 | 分层 + 一句预告 | |

## md 写法（`build_pptx.py` 的输入格式）

```markdown
# 第1章 走近细胞
> 人教版（2019）必修1 · 课时 1

## 01 虎克看到的"小房间"，其实已经死了
- 1665 年，软木塞薄片
- 他看到的是细胞壁，不是活细胞

<!-- note: 先让学生猜"这是活的还是死的"，再揭晓。停 5 秒。 -->

## 02 三个人的观察，拼出一个学说
| 人 | 看到了什么 |
|---|---|
| 虎克 | 死的细胞壁 |
| 列文虎克 | 活的细胞 |
```

规则：
- `##` 后是页标题，**写成结论句**（不要"细胞学说"）。
- 层级标题里的序号会被解析为页码。
- `<!-- note: … -->` 进 pptx 备注页，内容与逐字稿同源。
- 表格会渲染成两栏/多栏文本，**不画复杂表格**（真表格另出图）。
- 每页要点 ≤5 条，正文 ≤45 字。

## 页数

课时数 × 8–10。2 课时 → 16–20 页。超了就是没做减法。

## 生成

```sh
python3 scripts/build_deck.py --md "chapters/.../03-课件.md" --plan chapters/.../03-课件.plan.json \
  --out /tmp/ch01-C --images assets/deck-images/src --theme textbook --tag="-C教材"
```
输出 `03-课件-C教材.pptx`（16:9，原生可编辑，带讲稿备注）与 `03-课件-C教材-preview.html`（浏览器直接翻页）。换 `--theme academic|classroom|textbook` 出另外两版；版式规格见 `references/typography.md`。

## 生物学科的图怎么做

| 内容 | 做法 |
|---|---|
| 细胞结构 | 线描示意图（自绘 SVG 或简单图元），不要用有版权的教材插图 |
| 过程（分裂、光合、神经冲动） | 分步静态图 3–5 张，逐页出现；动态版放 07 视频 |
| 尺度（细胞 10µm ↔ 人体 1.7m） | 一条对数刻度尺，标 3 个锚点 |
| 分类（原核/真核、五大类群） | 树状图或双栏，不要超过 3 层 |
| 数据（实验、调查） | 一张表 + 一句话结论，不写"如图所示" |

## 交付前自检

- [ ] 页数在区间内；每页要点 ≤5 条
- [ ] 至少 1 页反例页，直接针对拆解里的迷思编号
- [ ] 抽查 5 页标题：都是结论句吗？
- [ ] 每页都有备注；备注里至少 1 句"停/问/看"
- [ ] 没有连续 30 字与教材一致
- [ ] `.pptx` 打开无溢出（文字框是否压到边线）
