# 板画六格 + 30 秒动画分镜

> 用途：板书顺序（教师在黑板上画）与微课分镜（做 30 s 动画）。
> 两者共用同一套图元，学生上课看到的图和课后看到的动画是"同一张图在动"，不是两套。

## 一、板画六格（按讲课顺序画，不要一次画完）

```
┌─ ① 两只手 ──────────┐   ┌─ ② 握手 = 肽键 ──────┐   ┌─ ③ 一滴水 ─────────┐
│  左手：氨基 —NH₂     │   │  —CO—NH—            │   │  H₂O               │
│  手里捏一个 H        │   │  （握在一起的那只手）│   │  O  ← 羧基          │
│  右手：羧基 —COOH    │   │                     │   │  H  ← 氨基 1 个      │
│  手里捏一个 OH       │   │                     │   │  H  ← 羧基 1 个      │
└──────────────────────┘   └─────────────────────┘   └────────────────────┘

┌─ ④ 珠子串 ──────────┐   ┌─ ⑤ 剪一刀 ──────────┐   ┌─ ⑥ 揉成团 ─────────┐
│ ●—●—●—●—●           │   │ ●—●—●  ●—●          │   │ ～～～↯～～～        │
│ 5 个珠子 4 个接缝    │   │ 2 条链：n−m          │   │ 同一串珠子，揉法不同 │
│ → 一条链 n−1        │   │ 首尾相接：n          │   │ 结构决定功能         │
└──────────────────────┘   └─────────────────────┘   └────────────────────┘
```

画法要点：
- ① 必须**让学生上来比一次手**，教师比过没用。两个人面对面，左手对右手。
- ③ 用两种颜色粉笔（O 红、H 白），这一格只画 20 秒，但能救一整类题（M2）。
- ④ 用磁扣或粉笔头串，**手指着数**："一个接缝、两个接缝……"，数到 n−1 再写公式。
- ⑤ 用手比"剪"的动作，剪一次，链变两条，接缝少 1。
- ⑥ 拿一张纸揉团，展开再揉一次（揉法不同）——这就是空间结构。

## 二、30 秒动画分镜（微课 / 课前预习）

| 时间 | 画面 | 旁白（括号为触发词） | 字幕 |
|---|---|---|---|
| 0:00–0:05 | 两个氨基酸并排，标出 —NH₂ 与 —COOH，微微靠近 | "两个氨基酸，靠过来。"（"靠过来"） | 氨基 · 羧基 |
| 0:05–0:12 | 左手捏的 H 与右手捏的 OH 被高亮（红/白） | "各松开一点：一个松 H，一个松 OH。"（"松"） | H ← 氨基　OH ← 羧基 |
| 0:12–0:18 | H 与 OH 飞出、合并成一滴水落下 | "合起来，掉下去——一滴水。"（"一滴水"） | 脱水 |
| 0:18–0:24 | 两个氨基酸之间出现 —CO—NH—，闪两下 | "接上的地方，叫肽键。"（"肽键"） | 肽键 —CO—NH— |
| 0:24–0:30 | 镜头拉远：5 个、10 个、一条长链；接缝逐个数出来 | "再接几个，就是一条链。数接缝，就是数水。"（"数接缝"） | 肽键数 = 氨基酸数 − 链数 |

旁白合计 62 字（≈ 2.1 字/秒，留出画面停顿）。旁白先录，动画按关键词触发；关键词处插 0.5 s 静默。

## 三、实现（最低成本）

```sh
# 6 张 1920×1080 图（PPT 导出 / 手绘拍照均可）→ shots/01..06.png
# 5 段旁白 → voice/01..05.mp3（第一段 5 s、其余按音频时长）
for i in 01 02 03 04 05 06; do
  D=$(ffprobe -v error -show_entries format=duration -of csv=p=0 "voice/$i.mp3")
  F=$(python3 -c "print(int($D*30)+12)")
  ffmpeg -y -loop 1 -i "shots/$i.png" -i "voice/$i.mp3" \
    -filter_complex "[0:v]scale=2400:-1,zoompan=z='min(zoom+0.0008,1.05)':d=$F:s=1920x1080:fps=30,format=yuv420p[v]" \
    -map "[v]" -map 1:a -c:v libx264 -crf 20 -c:a aac -shortest "seg$i.mp4"
done
printf "file 'seg01.mp4'\nfile 'seg02.mp4'\nfile 'seg03.mp4'\nfile 'seg04.mp4'\nfile 'seg05.mp4'\nfile 'seg06.mp4'\n" > list.txt
ffmpeg -y -f concat -safe 0 -i list.txt -c copy dehydro-30s.mp4
```

要"真的动"（H 和 OH 飞出去）就用 Manim，只做 0:05–0:18 这 13 秒，其余用静态图——不值得为 5 秒画面搭整套环境。

## 四、一致性检查

- [ ] 板画与动画的图元一致（同一套手/珠子/接缝）
- [ ] 动画里"数接缝"的数字与课堂上数的数字一致（5 个珠子 4 个接缝）
- [ ] 字幕不写教材页码，不抄教材插图
- [ ] 旁白关键词与画面动作逐句对齐（对不上就是两套东西）
