## 一、核心命题

| id | 命题 | 表征 | depth |
|---|---|---|---|
| P1 | 活化能：分子从常态转变为容易发生化学反应的活跃状态所需要的能量 | 能量曲线上"谷→峰"的落差 | 必考（定义题） |
| P2 | 酶通过**降低活化能**加快反应，不提供能量 | 峰顶下移 | 必考（易误） |
| P3 | 与无机催化剂相比，酶降低活化能的幅度更大，因此效率更高 | 两条曲线峰高不同 | 必考 |
| P4 | 酶不改变反应的起点与终点高度（不改变 ΔG / 反应能否发生） | 两端高度相同 | 必考（易误） |
| P5 | 酶不改变平衡点，只缩短到达平衡的时间 | 最终产物量相同 | 常考（易误） |
| P6 | 加热加快反应：给分子提供能量使更多分子达到活化能，与酶机制相反 | 两条温度曲线在高处分岔 | 必考（对比题） |
| P7 | 酶反应前后性质与数量不变，可反复使用 | "一滴研磨液分解一整瓶" | 基础 |
| P8 | 酶的本质：绝大多数是蛋白质，少数是 RNA | 举例 | 必考（边界） |
| P9 | 酶需适宜温度与 pH；高温、过酸过碱破坏空间结构，**不可逆**失活；低温抑制但可恢复 | 两条曲线 / 实验设计 | 常考 |
| P10 | 酶的催化效率受底物浓度（饱和）、酶浓度、温度、pH 共同影响，其中"平台段"往往不是活化能造成的 | 速率曲线 | 拓展 |

## 二、迷思与诊断信号

| id | 迷思 | 诊断信号 | 对应命题 |
|---|---|---|---|
| M1 | 酶给反应"提供能量 / 提供活化能" | 说"酶供能给反应"；把酶当 ATP | P2 |
| M2 | 酶能让本来不能发生的反应发生 | 认可"石墨加酶变金刚石" | P4 |
| M3 | 加酶后产物更多 / 反应更彻底 | 认为最终气体量不同 | P5/P10 |
| M4 | 酶都是蛋白质 | 否认 RNA 酶；只答"蛋白质" | P8 |
| M5 | 酶在反应中被消耗 | 说"要不断补加酶" | P7 |
| M6 | 酶催化的反应不需要能量 | 认为加酶后分子"不用激活" | P1/P2 |
| M7 | 酶在任何条件下都高效 | 高温题答"更快"；认为失活可恢复 | P9 |

## 三、表征（学生要能画的图）

| 图 | 画什么 | 判定要点 |
|---|---|---|
| 能量曲线 | 横轴反应过程、纵轴能量；三条：无催化剂、无机催化剂、酶 | 三条曲线**两端必须重合**，只有峰顶不同 |
| 加热 vs 加酶 | 同一张图上两条"加快"的曲线 | 加热不降峰，只让分布右移（更多分子越过原位峰） |
| 温度—活性曲线 | 钟形，60 ℃ 后陡降 | 左侧平缓（低温抑制），右侧断崖（结构破坏） |
| 底物浓度—速率曲线 | 先升后平台 | 平台高度由酶量决定，不由活化能决定 |

## 四、边界（这一节到哪儿为止）

- **到此为止**：活化能、酶降低活化能、与无机催化剂和加热的区别、酶的本质、失活的可逆性。
- **不要求**：酶的活性中心结构、诱导契合的分子细节、米氏常数、竞争性/非竞争性抑制、变构调节、酶原激活。
- **易混边界**：通道蛋白（第4章）是"让物质通过膜"，酶是"让反应通过壁垒"——两者都"降低难度"，但一个搬运物质、一个催化反应，**不能互相类比着讲**。

## 六、sources 与核验记录

- 教材：人教版（2019）必修1 第5章 第1节，图 5-1 为"酶降低活化能"的示意曲线（三条）。
- 课程标准：概念 2「细胞的生存需要能量和营养物质」，次位概念含"说明酶在代谢中的作用"。
- 数值说明：本知识点涉及的具体活化能数值（如 H₂O₂ 分解约 75 kJ/mol、酶催化下约 20 kJ/mol 量级）只作**量级示意**，课堂不要求记数字，考试也不考；课件与习题中一律标注"量级示意"。
- 事实核对：绝大多数酶是蛋白质、少数是 RNA（核酶）；高温使酶变性失活不可逆，低温只降低活性、回升后可恢复。两条均已对照教材正文与课标，不依赖单一教辅。
