# 知识点讲解设计 · 酶降低活化能

> 人教版（2019）必修1 第5章 第1节「降低化学反应活化能的酶」（第 1 课时：酶的作用）| 40 min | 高一上
> 前置：细胞代谢、ATP 是直接能源物质、第4章跨膜运输（"要花钱"的经验）
> 方法：`references/explain-protocol.md` 七步协议
> 这一份是**第三验证件**：脱水缩合"能算"、主动运输"有数据矛盾"、这一个**既算不出来、也没有现成矛盾**，只能靠一张能量图去想。用来检验七步协议在纯模型型知识点上是否还成立。

## 0. 一句话讲法（教师自用）

酶是一段**隧道**：山还是那座山，两头的高度一点没变，它只是把翻山的路凿低了——所以车过得快，但山没有变矮。

---

## 1. 靶（学完能做什么）

| # | 可观察行为 | 怎么验 |
|---|---|---|
| T1 | 给"无催化剂 / Fe³⁺ / 过氧化氢酶"三组同温同浓度数据，能排出速率顺序，并说"是活化能被降低的幅度不同" | 当堂 1 题，2 分钟 |
| T2 | 能在同一张坐标图上画出三条能量曲线，并指出"峰顶高度不同、两端高度相同" | 学案第 2 栏，学生画图 |
| T3 | 能说清"加热加快"与"酶加快"不是一回事：一个把分子抬上去，一个把门槛降下来 | 口头追问 2 人 |
| T4 | 能判断"酶能把一个本来不能发生的反应变得能发生"是错的，并给出理由（不改变平衡点） | 判断题 + 举手统计 |

四条都能当场看到，不写"理解酶的作用"这种动词。

## 2. 坎（学生会怎么想错）

| # | 他会怎么说 | 错在哪 | 什么题能钓出来 |
|---|---|---|---|
| M1 | "酶给反应提供能量 / 提供活化能" | 酶不提供能量，它**降低所需**的活化能；能量仍来自分子自身的热运动 | 问"酶催化时有没有能量输入" |
| M2 | "酶能把本来不能发生的反应变可能" | 酶只加快热力学上已经允许的反应，不改变反应能否发生 | 给"室温下石墨变金刚石加酶" |
| M3 | "加酶以后产物变多了 / 反应更彻底了" | 酶不改变平衡点，只改变到达平衡的速度 | 给"加酶与不加酶，最终气体总量相同" |
| M4 | "酶都是蛋白质" | 绝大多数是蛋白质，少数是 RNA（教材明说） | 直接问"有没有不是蛋白质的酶" |
| M5 | "酶在反应中被消耗掉了，所以要不断加" | 反应前后酶的性质和数量不变，可反复用 | 问"加一次酶能催化多少批底物" |
| M6 | "酶催化的反应不需要能量" | 仍需要活化能，只是门槛更低；低温下照样很慢 | 问"冰箱里的酶为什么不工作" |
| M7 | "酶在哪里都高效" | 需要适宜温度与 pH；高温、过酸过碱使空间结构破坏而**不可逆**失活 | 给"煮沸后冷却再加"的实验 |

七条里 M1 是"能量"这个词的误读，M3 是图表题的命门，M4/M7 是本节末尾与"酶的特性"的接缝。

## 3. 冲突（两处，各 2–3 分钟）

### 冲突 A：开场（5 min）——"几微克蛋白质，凭什么差几百倍"

```
同一瓶 H₂O₂，同一间教室，同一个温度。

A 组：只放着。            几小时过去，几乎看不到气泡。
B 组：滴入一滴肝脏研磨液。  气泡立刻涌出，带火星的木条复燃。

差别只有一个：B 组里多了几微克蛋白质（过氧化氢酶）。
问：这几微克蛋白质，做了什么？
```

学生第一反应："它把 H₂O₂ 分解了。"——对，但这不是答案，因为**它自己没有变少**，一滴研磨液能把整整一瓶 H₂O₂ 全部分解完。它没有"替"H₂O₂ 干活，它让 H₂O₂ **自己**分解得快了。

一句追问钉住：**"它没被用掉，也没给反应加能量——那它动了什么？"**

> 这就是纯模型型知识点的难处：学生看不见分子，也拿不到"算错"的把手。冲突只能靠"数量级不合理"来造：几微克 vs 一整瓶。

### 冲突 B：讲机制时用（3 min）——"两条路都能变快，但不是同一条路"

```
试管 1：H₂O₂ + 加热到 60 ℃      → 气泡变多（快）
试管 2：H₂O₂ + 煮沸 5 min 的研磨液 → 几乎没有气泡（停）
试管 3：H₂O₂ + 常温研磨液        → 大量气泡（最快）

问：都是"变快"，试管 1 和试管 3 的快，是一回事吗？
```

学生答"都是加快反应"，到这里就够。追问一句把两条路分开：

- 加热：给每个分子**更多能量**，本来只有少数分子能翻过山，现在翻过去的多了。
- 加酶：山没有变矮，分子也没有拿到更多能量，是**翻越的高度被降下来了**。

落点：**这两条路方向相反——一条把人抬上去，一条把山削下来。**

> 试管 2 是这堂课的"证人"：证明酶的快依赖它自身的空间结构，不是"蛋白质这个东西本身有什么魔力"。

## 4. 具象（一个类比撑到底）

**隧道。**

| 真实机制 | 隧道 |
|---|---|
| 反应要越过能量壁垒（活化能） | 从山谷翻到另一座山谷，要爬过垭口 |
| 无催化剂：只能硬爬 | 走垭口，慢 |
| 无机催化剂：把垭口降低一点 | 凿低一点，快一些 |
| 酶：把垭口降低很多 | 直接打一条隧道，最快 |
| 起点与终点的高度差不变（ΔG 不变） | 隧道不改变两座山谷的海拔 |
| 平衡点不变，只缩短到达时间 | 过隧道不改变目的地，只改变用时 |
| 酶与底物特异性结合 | 隧道口只容得下一种车 |
| 高温、过酸过碱破坏空间结构 → 失活 | 隧道塌方（而且**修不回来**） |

- **能数/能指的是什么**：垭口的**高度**（活化能）、两头的**高差**（ΔG）、洞口**形状**（专一性）、有没有**塌**（失活）。
- **哪里不像**（必须讲，讲漏了就会长出新迷思）：
  1. **隧道是"路"，酶是"手"**。分子不是从一条现成的通道里滑过去，而是先与酶结合，被"扶"过过渡态，再放出来。所以酶每次都有一轮"抓—扶—放"，而不是"过一下就完事"。这一条直接防住 M5（酶被消耗）和"酶=通道蛋白"的跨章混淆。
  2. **隧道对所有车开放，酶只认一种底物**。这不是细节，这是下一课时"专一性"的全部起点。
  3. **隧道不会塌，酶会塌，而且塌了长不回来**。高温失活不可逆，低温只是"冻住"（可恢复）——这一对差异是考试高频，也是本类比唯一"必须补一句"的地方。
  4. **隧道是永久的，酶会被降解、要不断合成**。这条只在学有余力时提，别占正课时间。

第 1 条和第 3 条是这一个知识点的"类比失效处 = 考点"。

## 5. 命名与压缩

顺序仍是：现象 → 矛盾 → 机制 → 名称。

1. **现象**：几微克蛋白质让一整瓶 H₂O₂ 在几十秒内分解完，而它自己没少。
2. **矛盾**：它没有被消耗，也没有给反应能量，凭什么让反应快了千百倍？
3. **机制**：它降低了反应所需的活化能——让更多分子能越过那道能量壁垒。
4. **名称**：这类物质叫**酶**，这类作用叫**催化作用**，这种"降门槛"的能力叫**降低活化能**。

> 一句定义（≤26 字，写在黑板上不再改）：
> **`酶：显著降低活化能的生物催化剂（多数是蛋白质）。`**

三件事的板书对照（只写这三行，多了不看）：

```
                能量              门槛            结果
加热          给分子加能量        不变          变快，分子更"疯"
无机催化剂      不加能量         降一点        变快，幅度有限
酶            不加能量         降很多        变得很快，且专一
```

## 6. 走变式（每个只变一个维度）

| 变式 | 变什么 | 学生要做的事 | 结论 / 会卡在哪 |
|---|---|---|---|
| V1 换催化剂 | 无 / Fe³⁺ / 过氧化氢酶 | 排速率、说理由 | 降幅越大越快；酶降得最多（M1 破） |
| V2 换温度 | 20 ℃ / 40 ℃ / 60 ℃ / 100 ℃ | 预测两条趋势 | 无酶时升温一直变快；有酶时先升后**断崖**（M7） |
| V3 换 pH | 过氧化氢酶（近中性）/ 胃蛋白酶（强酸） | 判断哪种条件下活性高 | 每种酶有自己的最适 pH；过酸过碱**不可逆**失活 |
| V4 换底物浓度 | 底物不断加 | 画/读速率曲线 | 先升后平：这一次的"平台"不是活化能，是**酶的量**（M3 的近邻陷阱） |

**V2 一定要两条线画在一起**：一条无酶、一条有酶。学生自己说"为什么这两条线在高温处分岔"。
**V4 是防伪题**：让学生分清"降门槛"（改变速度的斜率）和"酶不够用"（改变速度的上限）——这两件事在图上都能让曲线变平，但原因完全不同。

## 7. 回收（三个动作）

1. **同伴复述（2 min）**："30 秒，用隧道这个说法讲给同桌听。听的人只准问一句：**山变矮了吗？**"（答：没有，山没变矮，是路变短了。）
2. **一句边界（1 min）**："酶能不能让一个本来不能发生的反应发生？"——不能。它只让**能发生的**快点发生。所以"石墨加酶变金刚石"是错的。
3. **回到用处（2 min）**：为什么发烧到 39 ℃ 会难受？为什么加酶洗衣粉不能用开水？为什么医院查肝功能要看酶？——因为身体里几乎所有反应的速度，都由酶的"门槛高度"决定。

最后一句留在黑板上：

```
加热是把人抬上去，酶是把山削下来。
```

## 9. 教师关键句

1. "它没被用掉，也没给反应加能量——那它动了什么？"
2. "加热和加酶，一个是抬人，一个是削山。"
3. "山没有变矮，是路变短了。"
4. "隧道塌了能修，酶塌了修不回来。"
5. "酶不让反应发生，它只让反应快点发生。"

## 10. 常见坑

- **不要把活化能讲成"反应需要的总能量"**。它是"越过壁垒所需的那一点额外能量"，一字之差，后面 ΔG 与平衡点的判断全崩。
- **不要只画一条曲线**。必须有"无催化剂 / 无机催化剂 / 酶"三条同图，峰顶高度差是这节课唯一的视觉证据。
- **不要用"降低活化能"解释一切**。V4 的平台是酶量不足，跟活化能无关；不区分，学生会把所有曲线变化都归给活化能。
- **不要把"酶是蛋白质"说死**。教材明写少数酶是 RNA，说了"都是蛋白质"等于亲手造出 M4。
- **不要跳过"煮沸后冷却"这个实验**。它同时证伪"酶只是蛋白质的某种性质"和"低温失活可恢复"，性价比最高。
- **不要在这里展开酶促反应动力学**（米氏方程、抑制剂类型）——本节要求到"降低活化能 + 高效性"为止。
