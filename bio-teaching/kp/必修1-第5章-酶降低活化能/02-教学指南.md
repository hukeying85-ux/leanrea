# 教学指南 · 酶降低活化能（40 分钟，可直接上课）

> 高一上 · 人教版必修1 第5章第1节第1课时 | 一张黑板、一支粉笔、一瓶 H₂O₂ 就够
> 教师用。学生手上只有 `03-学生一页学案.md`。

## 0. 一句话讲法

酶是一段隧道：山还是那座山，两头高度一点没变，它只是把翻山的路凿低了。

## 1. 上课前 5 分钟检查

- [ ] 三支试管：只放 H₂O₂ / H₂O₂ + 肝脏研磨液 / H₂O₂ + **煮沸后冷却**的研磨液。第三支是本课的关键证据，别忘。
- [ ] 带火星的木条 3 根（或 3 个气球套住管口，看谁鼓得快）。
- [ ] 黑板左侧留出"三行对照表"的位置，整节课不擦。
- [ ] 学案发下去，但**先不让填**（第 1 栏留到最后）。

## 2. 流程与时间

| 时间 | 环节 | 你在做什么 | 学生 | 判断达标 |
|---|---|---|---|---|
| 0–5 | 冲突 A | 三支试管并排演示，只问"这几微克蛋白质做了什么" | 看、猜、写一句猜想 | 有人说"它自己没少"就到位 |
| 5–15 | 具象 + 命名 | 画能量图（无催化剂），再画加酶；隧道类比 | 在学案第 2 栏画三条曲线的**前两条** | 能指出"峰矮了，两头没动" |
| 15–20 | 三行对照 | 加热 / 无机催化剂 / 酶，逐行填 | 补学案第 3 栏 | 能说出"加热不给门降门槛" |
| 20–30 | 变式 | V1 换催化剂、V2 换温度、V3 换 pH、V4 换底物浓度 | 逐题判断并说依据 | 4 题至少 3 题对，且理由不是"因为酶厉害" |
| 30–35 | 边界与意义 | 煮沸的研磨液为什么失效；少数酶是 RNA；发烧、洗衣粉 | 举一个生活例子 | 能说出"失活不可逆、低温可恢复" |
| 35–40 | 回收 | 同伴互讲 30 秒，只准问"山变矮了吗"；留一句板书 | 互讲、改学案 | 全班能齐答"没有变矮" |

**讲 17 / 练 18 / 收 5**。练的时间全部在画图和判断上，不是在抄定义。

## 3. 板书设计（三块，从左到右）

```
┌──────────────┬──────────────────┬─────────────────────┐
│  ① 能量图      │  ② 三行对照        │  ③ 一句话            │
│              │                  │                     │
│ 能量          │        能量  门槛  结果                 │
│  ↑  ╱╲       │ 加热     加    不变  变快              │
│     ╱  ╲      │ 无机催化  不加  降一点 变快            │
│  ──╱    ╲──   │ 酶      不加  降很多 很快且专一         │
│   反应过程     │                  │                     │
├──────────────┴──────────────────┴─────────────────────┤
│ ④ 收句：加热是把人抬上去，酶是把山削下来。                  │
└───────────────────────────────────────────────────────┘
```

画能量图时**先画山谷，再画垭口，最后凿隧道**。顺序反过来，学生只会看到一条漂亮的线，不会看到"为什么需要能量"。

## 4. 关键提问（按顺序问，不要跳）

1. "它没被用掉，也没给反应加能量——那它动了什么？"（开场唯一的问题）
2. "加热也能让它快，这两件事一样吗？"（学生答"一样"是正常的，别急）
3. "峰顶降下来了，两头的山谷动了吗？"（这一问定 P4）
4. "酶让反应更彻底了吗？"（这一问定 P5）
5. "煮沸的研磨液为什么不行？山塌了还能修吗？"（这一问定 P9）

## 5. 当堂诊断（3 题，各 1 分钟，选择题举手统计）

**1.** 下列关于酶的作用的叙述，正确的是（　）
A. 酶为反应提供能量　B. 酶降低反应的活化能　C. 酶改变反应的平衡点　D. 酶使不能发生的反应发生
→ **B**

**2.** 把 H₂O₂ 分别加入：①常温研磨液 ②煮沸后冷却的研磨液 ③FeCl₃ 溶液。气泡量由多到少的顺序是（　）
A. ①②③　B. ①③②　C. ③①②　D. ②①③
→ **B**

**3.** 加酶与不加酶，最终生成的 O₂ 总量（　）
A. 加酶更多　B. 加酶更少　C. 相同　D. 无法比较
→ **C**

三题全对率低于 60%：下一课时开头 3 分钟只补第 3 题（平衡点）。

## 6. 学生一定会问的四个问题

| 他问 | 你怎么答 |
|---|---|
| "酶为什么能降低活化能？" | 它先把底物**抓住**，扶着它换一个更容易变形的姿势——这不是"给能量"，是"改变路径"。分子细节本课时不讲，讲清"抓—扶—放"即可。 |
| "酶会不会用完？" | 不会，反应前后它不变，一滴研磨液能分解一整瓶 H₂O₂。这就是催化剂的意思。 |
| "煮沸后为什么不能恢复？" | 高温把它的空间结构弄散了，像鸡蛋煮熟。低温只是"冻住"，回暖还能动。 |
| "那加热不是更省事？" | 加热会烧坏细胞里的其它东西。细胞要的是"在 37 ℃ 下把某一步加快"，只能靠酶。 |

## 7. 时间不够时的删减顺序

先删 V4（底物浓度），再删 V3（pH，留给第 2 课时"酶的特性"），**冲突 A、三条能量曲线、煮沸对照三样绝不能删**。

## 8. 下水提醒

- 研磨液现配现用，放久了活性下降，"煮沸组没气泡"就证明不了什么。
- H₂O₂ 浓度别太高（3% 足够），浓度一高，无酶组也冒泡，冲突 A 就废了。
- 演示时先让学生预测"哪支最快"，再动手。预测写下来，后面回头对，效果最好。
