# 板画六格 + 30 秒动画分镜（主动运输）

> 板书与微课共用同一套图元：浓度坡、泵、构象三连、三栏表、双曲线、囊泡。

## 一、板画六格（按讲课顺序画）

```
┌─ ① 浓度坡 ─────────────┐  ┌─ ② 水泵 ────────────┐  ┌─ ③ 构象三连 ────────┐
│ 外  K⁺ 5   ┃           │  │   膜 ┌──泵──┐       │  │  (朝外)  (结合)  (朝内)│
│ 内  K⁺ 140 ┃           │  │ 水 低 →→→ 高         │  │   ＼__/   ⊂●⊃    /‾‾＼ │
│ 顺浓度只能到平，        │  │   电：ATP            │  │  载体不搬家，只换姿势  │
│ 它却越吸越多 → 有第三种 │  │   泵口只过一种（特异）│  │  → 物质从中间过去     │
└────────────────────────┘  └──────────────────────┘  └──────────────────────┘

┌─ ④ 三栏判定 ───────────┐  ┌─ ⑤ 双限制 ──────────┐  ┌─ ⑥ 囊泡 ────────────┐
│      方向  载体  能量   │  │ 速率↑  ╱‾‾‾‾（饱和） │  │  ◯ → ◡ → ⊂◯⊃        │
│ 自由   ↓    ✗    ✗     │  │      ╱               │  │  凹陷→包裹→脱离      │
│ 协助   ↓    ✓    ✗     │  │  ────→ 浓度          │  │  耗能、无载体、靠流动 │
│ 主动   ↑    ✓    ✓     │  │ 速率↑  ╱‾‾‾（缺氧）  │  │  ≠ 主动运输          │
└────────────────────────┘  └──────────────────────┘  └──────────────────────┘
```

画法要点：
- **①** 用三条横线画坡，标数字，不写单位；接着画一个"越吸越多"的箭头，制造矛盾。
- **②** 泵必须画**嵌在膜里**（不是浮在膜上），这是 M3 的第一道防线。
- **③** 三连图至少画两次：一次教师画，一次让学生上来改错的版本（把载体画到对面）。
- **④** 这一格是本课工具箱，留在黑板上**不擦**，后面所有题都指它。
- **⑤** 两条曲线共用一个坐标系的两块区域，标清横轴是"浓度"还是"O₂"。
- **⑥** 用两个粉笔头夹住一张纸比"包裹"，比画图直观。

## 二、30 秒动画分镜

| 时间 | 画面 | 旁白（括号为触发词） | 字幕 |
|---|---|---|---|
| 0:00–0:06 | 两根柱子：细胞内 K⁺ 高、细胞外低；箭头却继续向内 | "里面的钾离子，已经比外面多了。"（"多了"） | 内高外低 |
| 0:06–0:14 | 膜上出现一台泵，ATP 图标亮起，泵开始工作，箭头逆着柱子上升 | "它还在往里搬。要花电。"（"花电"） | 逆浓度 · 耗 ATP |
| 0:14–0:22 | 泵的三连构象：朝外 → 结合 K⁺ → 朝内 → 释放 | "泵不搬家，它只是换个姿势。"（"换个姿势"） | 载体不移动，只改变构象 |
| 0:22–0:30 | 断电：ATP 熄灭，泵停住，柱子的高度差开始回落 | "断电，它就停了。"（"停了"） | 抑制呼吸 → 运输停止 |

旁白 58 字（≈2 字/秒，留停顿）。关键词后各停 0.5 s，动画按关键词触发。

## 三、实现（最低成本）

```sh
# 6 张 1920×1080 图（PPT 导出/手绘拍照）→ shots/01..06.png；4 段旁白 → voice/01..04.mp3
for i in 01 02 03 04 05 06; do
  D=$(ffprobe -v error -show_entries format=duration -of csv=p=0 "voice/$i.mp3")
  F=$(python3 -c "print(int($D*30)+12)")
  ffmpeg -y -loop 1 -i "shots/$i.png" -i "voice/$i.mp3" \
    -filter_complex "[0:v]scale=2400:-1,zoompan=z='min(zoom+0.0008,1.05)':d=$F:s=1920x1080:fps=30,format=yuv420p[v]" \
    -map "[v]" -map 1:a -c:v libx264 -crf 20 -c:a aac -shortest "seg$i.mp4"
done
printf "file 'seg01.mp4'\nfile 'seg02.mp4'\nfile 'seg03.mp4'\nfile 'seg04.mp4'\nfile 'seg05.mp4'\nfile 'seg06.mp4'\n" > list.txt
ffmpeg -y -f concat -safe 0 -i list.txt -c copy active-transport-30s.mp4
```

0:14–0:22 的构象变化如果要做"真动"，用 Manim 只做这 8 秒（三个 `Polygon` + `Transform`），其余静态图。

## 四、一致性检查

- [ ] 板画的泵始终嵌在膜里（不能画成浮在膜外）
- [ ] 动画里三连构象的顺序与板画一致（朝外 → 结合 → 朝内）
- [ ] 断电那一幕与课堂的"抑制剂实验"用的是同一个说法（"断电/停"）
- [ ] 字幕不抄教材插图，不标教材页码
- [ ] 数值只用"内高外低"的定性表述，不写具体 mmol/L（避免与不同教材版本冲突）
