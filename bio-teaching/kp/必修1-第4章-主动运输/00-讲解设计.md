# 知识点讲解设计 · 主动运输

> 人教版（2019）必修1 第4章 第2节「主动运输与胞吞、胞吐」| 40 min | 高一上
> 前置：被动运输（自由扩散、协助扩散）、细胞膜的结构、ATP 是直接能源物质
> 方法：`references/explain-protocol.md` 七步协议
> 这一份是**验证件**：上一个知识点（脱水缩合）是"能算的"，这个是"看不见、只能推的"，用来检验七步协议是否通用。

## 0. 一句话讲法（教师自用）

主动运输就是给细胞膜装了一台**水泵**：水往低处流，它偏要把水往高处抽——要电（ATP）、泵口只过一种东西（特异性）、泵的数量固定（会饱和）。

---

## 1. 靶（学完能做什么）

| # | 可观察行为 | 怎么验 |
|---|---|---|
| T1 | 给一张细胞内外离子浓度表，能判断某物质进入细胞的方式，并给出"方向 / 载体 / 能量"三条依据 | 当堂 1 题，2 分钟 |
| T2 | 能解释"缺氧为什么让吸收变慢，且不可能无限加快" | 口头追问 1 人 |
| T3 | 能指出"载体蛋白把物质抱着运过去"这句话错在哪 | 判断题 + 白板改图 |
| T4 | 能说出胞吞胞吐为什么不算主动运输（都耗能，差别在载体与分子大小） | 变式题 1 道 |

四条都能当场看到，不需要"理解"这种动词。

---

## 2. 坎（学生会怎么想错）

| # | 他会怎么说 | 错在哪 | 什么题能钓出来 |
|---|---|---|---|
| M1 | "主动运输只要耗能就行，不一定需要载体" | 三个要素缺一不可：逆浓度、载体、能量 | 问"没有载体蛋白的膜，还能主动运输吗" |
| M2 | "只要耗能就是主动运输" | 胞吞胞吐也耗能，但不用载体、运的是大分子/颗粒 | 给"白细胞吞噬细菌" |
| M3 | "载体蛋白自己移动，把物质抱过去" | 载体**不移动**，是构象改变（开口朝外→朝内），物质从它中间过去 | 判断题 + 让学生改图 |
| M4 | "主动运输只能把物质运进细胞" | 双向：也可把 Ca²⁺、Na⁺ 泵出细胞 | 给"细胞排出 Ca²⁺"的数据 |
| M5 | "浓度差越大，运输越快，没有上限" | 受载体数量限制（饱和）与能量限制（双限制） | 速率—浓度曲线、速率—O₂ 曲线 |
| M6 | "主动运输不受温度影响" | 载体是蛋白质，温度影响其构象；能量供应也受温度影响 | 低温实验题 |
| M7 | "小分子被动、大分子主动" | 与分子大小无关，与"是否逆浓度 + 是否耗能 + 是否需要载体"有关 | 葡萄糖（小分子，可主动可协助） |

七条里，M3 是"看不见机制"的典型误读，M5 是图表题的命门，M2 是跨节边界。

## 3. 冲突（两处，各 2–3 分钟）

### 冲突 A：开场（5 min）——"它凭什么越吸越多"

```
任务：下面是某细胞内外三种离子的浓度（示意，量级正确）

            细胞内      细胞外
   K⁺        140         5        （内高外低）
   Na⁺        12        145        （外高内低）
   Ca²⁺     0.0001        2        （外高内低）

问：细胞要把 K⁺ 继续吸进细胞，可能吗？
学生直觉："不可能，浓度已经比外面高了，只能往外跑。"
事实：细胞内的 K⁺ 一直是高的，而且靠"吸"维持。
```

他为什么会愣：他脑子里只有"扩散"一种运输方式，扩散只能把浓度差抹平，抹平以后就停了。**但他刚学的自由扩散、协助扩散都做不出"越吸越多"这件事**——必须有第三种方式。

一句追问就够："如果只剩扩散，细胞里的 K⁺ 早该漏光了。它为什么没漏光？"

### 冲突 B：讲机制时用（3 min）——"断电会怎样"

```
实验：用呼吸抑制剂（如氰化物）处理该细胞 → 细胞对 K⁺ 的吸收几乎停止；
      洗去抑制剂、恢复供氧 → 吸收恢复。
问：这说明什么？
学生答："说明吸收需要能量。"
追问：能量从哪来？——细胞呼吸。抑制剂抑制了哪一步？——ATP 的生成。
```

落点：**逆浓度这件事，一定有人付钱。** 付钱的是 ATP。

> 这两处冲突合起来，正好把"逆浓度"与"耗能"两件事各自钉住，剩下的"载体"用饱和现象补（见变式）。

## 4. 具象（一个类比撑到底）

**水泵（抽水机）。**

| 真实机制 | 水泵 |
|---|---|
| 浓度梯度 | 水位差（水往低处流） |
| 主动运输（逆浓度） | 把水从低处抽到高处 |
| ATP 供能 | 电 |
| 载体蛋白 | 泵体本身（固定在墙上，不搬家） |
| 构象改变 | 泵叶轮转一圈，每次挤过去一点 |
| 特异性 | 泵口只接一种口径的管子 |
| 载体数量有限 → 饱和 | 泵的台数固定，再多水也抽不快 |
| 呼吸抑制剂 | 断电 |

- **能数/能指的是什么**：泵的**台数**（饱和）、**开/关**（能量）、**口径**（特异性）。
- **哪里不像**：
  1. 载体蛋白不是转子，它靠**构象改变**（开口朝外 → 结合 → 开口朝内）把物质"让"过去，自己不移动；
  2. 能量不是电，是 ATP 水解；
  3. 水泵只朝一个方向抽，真实载体有的能双向（但每次仍只顺/逆其浓度梯度方向工作）；
  4. 膜不是墙，是流动的脂双层——所以还有胞吞胞吐这种"整块搬运"的方式（水泵做不到）。

第 3 条"不像"正是 M3 的解药，必须在课堂上说出来，不能留给学生自己想。

## 5. 命名与压缩

顺序仍是：现象 → 矛盾 → 机制 → 名称。

1. **现象**：细胞能把 K⁺ 从低浓度一侧运到高浓度一侧，而且这件事会随缺氧停下来。
2. **矛盾**：扩散只会抹平浓度差，为什么它能"制造"浓度差？
3. **机制**：膜上有载体蛋白，消耗 ATP，把物质逆着浓度梯度转运。
4. **名称**：这种方式叫**主动运输**。

> 一句定义（≤25 字，写在黑板上不再改）：
> **`主动运输：逆浓度梯度、耗能、需要载体蛋白。`**

三要素板书（学生以后判断任何一题都靠这三栏）：

```
        方向        载体      能量
主动运输  逆浓度  →   要    →   要（ATP）
```

## 6. 走变式（每个只变一个维度）

| 变式 | 变什么 | 学生要做的事 | 结论 / 会卡在哪 |
|---|---|---|---|
| V1 换方向 | 从"吸进"改成"排出"（细胞把 Ca²⁺ 泵到细胞外） | 判断方向是否逆浓度、是否耗能 | 主动运输是双向的（M4 破） |
| V2 换条件 | 缺氧 / 加呼吸抑制剂 / 低温 | 预测速率变化 | 速率下降，但不为零（还有少量 ATP 与其它途径）；低温还影响载体构象（M6） |
| V3 换限制因素 | 浓度继续升高（载体已饱和） | 画/读速率曲线 | 速率不再上升 → 载体数量限制（M5） |
| V4 换分子大小 | 大分子（蛋白质、细菌）进出 | 判断是否算主动运输 | 不算：胞吞胞吐，耗能但无载体（M2、M7） |

**V3 一定要画曲线**：横轴浓度、纵轴速率，先升后平。让学生自己说"平的那一段是被什么卡住了"。
**V4 是边界题**：三条判据里"载体"这一栏填不出来，就不是主动运输。

## 7. 回收（三个动作）

1. **同伴复述（2 min）**："30 秒，用水泵这个说法，把主动运输讲给同桌听。听的人只准问一句：泵在哪儿？"
2. **一句边界（1 min）**："三种跨膜方式里，哪一种不是'跨膜'？"（胞吞胞吐：靠膜的流动性，形成囊泡）
3. **回到用处（2 min）**："细胞为什么非要花钱做这件事？"——因为它要**按自己的需要**选择吸收（哪怕外面很稀），也要把废物、有害物质排出去。花钱买的是"选择权"。

最后一句留在黑板上：

```
扩散是顺其自然，主动运输是有所选择。
```

## 9. 教师关键句

1. "扩散只会把水端平，它凭什么把水往高处抽？"
2. "断电以后，泵还转吗？"
3. "载体不搬家，它只是换个姿势。"
4. "平的那一段，是被什么卡住了？"
5. "它花钱买的不是物质，是选择权。"

## 10. 常见坑

- **不要一上来就列三种运输方式对照表**。表是结论，先让学生撞一次墙（冲突 A），表才有意义。
- **不要说"主动运输需要载体蛋白协助"就完事**。M3 的根源就是没人讲构象改变，只讲"协助"。
- **不要把"耗能"等同于"ATP 直接供能"之外的细节**（协同运输的二次主动运输不在本节要求内，别展开）。
- **不要用"逆浓度"当唯一判据**。有些题给的是"维持浓度差"，本质仍是逆浓度；反过来，只给"耗能"也不能定案（胞吞胞吐）。
- **不要跳过"为什么值得"**。这一节的落点是"选择权"，不是三个名词。
- **不要让学生背"主动运输的三个特点"**。让他们用三栏去判题，判得多了自然就记住。
