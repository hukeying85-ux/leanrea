## 一、核心命题

| id | 命题 | 表征 | depth |
|---|---|---|---|
| P1 | 主动运输：细胞逆浓度梯度，经载体蛋白，消耗能量（ATP）转运物质 | 三栏表 | 必考 |
| P2 | 载体蛋白有特异性；转运时发生**构象改变**，载体本身不移动 | 三连图 | 必考（易误） |
| P3 | 主动运输可进可出（如把 Ca²⁺ 泵出细胞） | 双向箭头 | 必考 |
| P4 | 速率受能量限制（缺氧、呼吸抑制剂降低）与载体数量限制（饱和） | 两条曲线 | 常考 |
| P5 | 判断运输方式看三件事：方向、载体、能量 | 判定流程 | 必考 |
| P6 | 自由扩散：顺浓度、不需载体、不耗能（O₂、CO₂、甘油、乙醇） | 举例 | 基础 |
| P7 | 协助扩散：顺浓度、需载体、不耗能（葡萄糖进入红细胞） | 举例 | 基础 |
| P8 | 胞吞胞吐：大分子/颗粒，耗能、不需载体、依赖膜的流动性 | 膜凹陷/融合 | 常考（边界） |
| P9 | 意义：按需选择吸收、排出废物与有害物质，维持细胞内成分相对稳定 | 一句话 | 必考（落点） |
| P10 | 温度影响主动运输：既影响载体（蛋白质）构象，也影响能量供应 | 双因素 | 拓展 |

## 二、迷思与诊断信号

| id | 迷思 | 诊断信号 | 对应命题 |
|---|---|---|---|
| M1 | 主动运输只要耗能，不必需载体 | 问"无载体能否主动运输"答"能" | P1 |
| M2 | 只要耗能就是主动运输 | 把胞吞胞吐归为主动运输 | P8/P5 |
| M3 | 载体蛋白自己移动把物质抱过去 | 画图时载体画到膜另一侧 | P2 |
| M4 | 主动运输只能进不能出 | 见"排出 Ca²⁺"判成被动 | P3 |
| M5 | 浓度差越大速率越快、无上限 | 不认"平台段" | P4 |
| M6 | 温度不影响主动运输 | 低温题答"无影响" | P10 |
| M7 | 小分子被动、大分子主动 | 葡萄糖一律判成主动运输 | P5/P7 |

## 五、边界（讲到哪里为止）

- **必讲**：P1–P5、P8、P9。
- **可讲**：P4 的两条曲线、P10 温度（有图表题的班型）。
- **不讲**：协同运输/二次主动运输、钠钾泵的分子细节（选必 1）、泵的抑制剂种类。
- **口径提醒**：教材把主动运输定义为**逆浓度梯度**；不要引入"有些主动运输顺浓度"的拓展说法，会与考试口径冲突。
- **易混词**：跨膜运输（自由扩散/协助扩散/主动运输）≠ 非跨膜运输（胞吞胞吐）。
