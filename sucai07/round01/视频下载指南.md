# 原视频下载指南（需在本地执行）

> 说明：本次工作环境的出站网络仅允许 GitHub / npm / PyPI，无法直连 YouTube，
> 因此原视频 MP4 需要你在本地电脑用 GitHub 开源工具 **yt-dlp** 下载后，
> 手动拖入 Google Drive：`我的云端硬盘/一二和布布 - 原始素材/素材 07/`

## 推荐工具：yt-dlp（GitHub ★205k+）

仓库：https://github.com/yt-dlp/yt-dlp

## Windows 一键命令（PowerShell）

```powershell
# 安装（任选其一）
winget install yt-dlp.yt-dlp
# 或: pip install -U yt-dlp

# 下载最高画质 MP4 到 G 盘云端硬盘目录
yt-dlp -f "bv*[ext=mp4]+ba[ext=m4a]/b[ext=mp4]" `
  -o "G:\我的云端硬盘\一二和布布 - 原始素材\素材 07\%(title)s.%(ext)s" `
  "https://www.youtube.com/shorts/bkGhmZLOAwI"
```

## 可选参数

- 顺带下载封面与字幕：`--write-thumbnail --write-auto-subs --sub-langs "zh.*,en"`
- 只要 1080p 以内：`-f "bv*[height<=1080]+ba/b"`
- 碰到风控报错时加：`--cookies-from-browser chrome`
