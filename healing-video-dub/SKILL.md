# healing-video-dub：一套 3D 丝滑模板 × 无限换文案克隆配音（A1 架构）

一个 `SKILL.md` + 三个脚本（`probe_template.py` 勘测槽位 / `clone_and_dub_a1.py` 克隆合成验收 / `expand_30s_template.py` 30s 扩容），不需要 MCP、不需要付费 TTS API、不需要每次重跑视频扩散大模型。

**第一原则（本项目 A/B 实测结论）：有成熟 3D 动画底片时，永远走 A1（原片连续 24fps H.264 视频流 `-c:v copy` + 零漂移克隆音轨），别拿静态关键帧光流硬凑。**
实测对比：8 张静态帧 + CPU 光流的冻结帧占比高达 `60.17%`（肉眼 PPT 卡顿）；免费 T4 跑 `Wan2.1-1.3B + RAFT` 虽能把冻结帧压到 `1.67%`，但受潜空间分辨率限制，1080p 纹理锐度（Laplacian `5.4`）仍不及 **A1 架构（冻结帧 `0.00%`、PSNR `51.95 dB`、锐度 `15.2`、视频流合成耗时 `0.02s`）**。

**第二原则：好配音不是「把字念出来」，而是「卡进角色张嘴窗 + 躲开动作音效窗」。**
底片里 `3.50s` 撸妹正把嘴唇贴在噜噜脸颊上亲吻（伴奏轨含真实 `mua~` 音效）——人声若侵入 `[3.32s, 4.12s]` 半秒，画面立刻穿帮。先锁槽位与禁区，再按槽位字数写台词，最后用 `F5-TTS` 的 `fix_duration` 原生控长 + `Seed-VC` 44.1kHz 提纯音色，才能做到「换了新词也像原片原生配音」。

## 何时用 / 何时别用

- **用**：已有无水印 3D/2D 治愈情侣动画底片（如水豚「噜噜 & 撸妹」），想批量换文案做日常连载；想保留原片丝滑微表情、晨间吉他 BGM 与亲吻动作音效，只替换高还原度角色克隆配音；想把 10s 模板扩展成 30s 三幕剧情。
- **别用**：需要角色做出底片里完全不存在的新肢体动作（如从卧室瞬移到海边冲浪）——此类场景需换新底片，或在 `24GB+` 显卡上跑 `Wan2.1-14B-720P` 视频生成。

## 1. 模板勘测（新底片只做一次，产出 `template_manifest.json`）

拿到任意一条无水印参考视频后，先做两件事：
1. **音轨无损二分**：用 `htdemucs` 拆成 `vocals.flac`（纯人声，用来提取干净角色参考声纹 `refs/*.flac` 与原始开口时间窗）和 `no_vocals.flac`（纯伴奏 + 亲吻/环境动作音效，永久复用为模板底噪轨）。
2. **底片转通用硬解封装 + 抽帧核验嘴型**：原片常为 HEVC (`hvc1`)，部分浏览器软解易掉帧；一次性转码为无声 `H.264 High@L4.0 CRF15 yuv420p +faststart`，随后运行：

```sh
python3 scripts/probe_template.py \
  --video templates/capybara_morning_10s/video_1080p24_muted.mp4 \
  --vocals raw_vocals.flac \
  --out-strip lip_strip.png \
  --out-json probed.json
```

打开 `lip_strip.png` 逐格确认每段是谁在张嘴、哪一段是肢体互动禁区。内置模板 `capybara_morning_10s`（`10.08s`，`241帧@24fps`）实测标准时间表如下：

## 2. 槽位文案设计（延续「触发 → 温柔接住」两回合四拍结构）

10 秒正好容纳 **两轮「撒娇触发 → 宠溺接住」**，与本仓库 `healing-comic` 的引导型恋人内核完全互通：

## 3. 开源双引擎零样本语音克隆（`F5-TTS` + `Seed-VC 44.1kHz`）

为什么单靠一个 TTS 模型不够好？
- 只用 **F5-TTS (`SWivid/F5-TTS` · `F5TTS_v1_Base`)**：能从任意新中文文本自然生成停顿与语气，且支持 `fix_duration = ref_dur + slot_dur` 在 Flow-Matching 潜空间原生控制时长，但默认输出为 `24kHz`，高频空气感与中文细微声纹（`CAMPPlus` 约 `0.25~0.45`）略欠火候；
- 级联 **Seed-VC (`Plachtaa/seed-vc` · `BigVGAN` + `CAMPPlus`)**：以 F5-TTS 生成的新台词干声为内容源（`f0_condition=False, auto_f0_adjust=True, diffusion_steps=35`），二次精修为目标角色音色，实测中文声纹相似度 `CAMPPlus` 直接跃升至 **`0.52 ~ 0.70`**，`WavLM-SV` 达 **`0.9567 ~ 0.9608`**。

### 四条工程铁律（全是从踩坑里省下来的时间）

1. **多随机种子候选择优**：每句跑 `2~3` 个配置（`fix_duration` 控长种 + 自然语速种），优先选有效发音时长（`-36dB` 门限裁边后）最接近槽位时长的一条送入 `Seed-VC`，这样混音时 `atempo` 接近 `1.0x`，彻底杜绝加速变调的「花栗鼠音」。
2. **绝不用线性重采样改语速**：微调时长必须走 `FFmpeg atempo`（WSOLA 保调时域伸缩），且门禁限制在 `1.00x ~ 1.25x` 以内；超出说明字数写多了，回去删 2 个字，别硬压音频。
3. **PyTorch 2.5+ 音频后端补丁**：新版 `torchaudio.load/save` 默认强依赖 `TorchCodec` 易报错，脚本内置 `soundfile` 透明接管补丁，Windows / Linux / Colab Python 3.12 零报错通跑。
4. **云端 GPU 严格「即用即停」**：若借用云端 Colab / Kaggle T4 跑克隆，必须在 `finally:` + CI `if: always()` 双重保底执行 `colab stop` 并校验活跃会话归零，杜绝算力空转。

## 4. 一键合成与四重自动验收

```sh
cd healing-video-dub

# 模式 A：使用已克隆干声极速合成 + 导出波形核验图（耗时 ~0.4 秒）
python3 scripts/clone_and_dub_a1.py examples/spec-weekend-snuggle.json \
  --out examples/output/weekend_snuggle_a1_10s.mp4 \
  --qa-json examples/output/weekend_snuggle_qa.json \
  --qa-plot examples/output/weekend_snuggle_timeline_qa.png

# 模式 B：本地有 NVIDIA GPU（≥4GB 显存）或 CPU，改完 spec.json 直接现场克隆 + 出片
python3 scripts/clone_and_dub_a1.py examples/spec-weekend-snuggle.json \
  --clone-on-the-fly --engine hybrid --seed-vc-dir /path/to/seed-vc \
  --out examples/output/my_new_episode.mp4
```

### 四重自动门禁（任一不过即报错阻断）
1. **语速门禁**：单句有效汉字语速必须在 `[2.2, 6.8]` 字/秒内（最佳甜区 `4.0 ~ 5.3` 字/秒）。
2. **禁区零泄漏门禁**：`sfx_guard_zones`（如 `[3.32s, 4.12s]` 亲脸颊区）内人声总线峰值必须 `< 0.0001`，同时动态闪避器（Sidechain Ducking `-2.5dB`）仅在说话瞬间压低吉他伴奏，亲吻音效保持 `100%` 清脆度。
3. **视频流零损门禁**：输出必须为 `1080×1920 @ 24.0fps`、`H.264 yuv420p`、`+faststart`（走 `-c:v copy` 零重编码损耗）。
4. **声纹一致性参考线**：`WavLM-Base-Plus-SV` 余弦相似度建议 `≥ 0.72`（噜噜实测 `0.95+`，撸妹实测 `0.72~0.80`）。

## 5. 从 10 秒扩展到 30 秒：耗时基准与三种扩容方案

### 5.1 30 秒成片实测耗时表（约 3 幕 × 4 句 = 12 句对白）

| 运行环境与环节 | 10 秒成片（4 句） | **30 秒成片（12 句）** | 说明 |
| :--- | :---: | :---: | :--- |
| **本地 GPU 热启动**（RTX 3060/4060/4090，模型常驻显存） | **`~15 秒`** | **`~40 – 55 秒`（不到 1 分钟）** | `F5-TTS` 约 `1.0s/句` + `Seed-VC` 约 `1.4s/句` + 混音封装 `4s` |
| **本地 GPU 仅跑 `F5-TTS` 快速模式**（省去 Seed-VC 二次精修） | **`~5 秒`** | **`~12 – 18 秒`** | 适合快速试听文案节奏，定稿后再开 `hybrid` |
| **云端 Colab T4 冷启动（含「即用即停」自动销毁）** | **`~3.0 分钟`**（实测 `181.6s`） | **`~3.8 – 4.5 分钟`** | 环境安装与拉权重固定占 `~2.5 分钟`，多 8 句台词仅多花 `~35 秒` |
| **纯 CPU 无显卡电脑**（16GB 内存） | `~45 – 70 秒` | **`~2.5 – 4 分钟`** | 自动降为 `16 NFE steps`，无需显卡也能跑 |
| **对比：若用方案 B（`Wan2.1` 视频大模型重绘 30s 画面）** | `~10 分钟`（单路 T4） | **`~25 – 30 分钟`**（T4） | 算力开销大 30 倍且 1080p 锐度下降，日常换文案不建议 |

### 5.2 10 秒底片如何无卡顿扩成 30 秒？（严禁直接 `0.33x` 慢放！）

直接把 10s 视频慢放 3 倍会出现明显抽帧与太空慢动作感。正确做法由 `scripts/expand_30s_template.py` 提供两种零卡顿模式（合成仅需 **`4~6 秒`**）：

1. **`--mode multi_clip`（同 IP 多镜头拼接，最推荐）**：
   收集同系列 3 条不同动作的 10s 无水印底片（如：`第1幕 清晨偷亲 10s` + `第2幕 被窝撒娇 10s` + `第3幕 端早餐投喂 10s`），按三幕剧拼接成 `30.24s` 连续 24fps 底片，伴奏轨自动 `120ms` 交叉淡化循环 3 周，保持 `100%` 原生 A1 丝滑度（范例配置见 `examples/spec-milk-tea-30s.json`）。
2. **`--mode pingpong`（单底片正反演闭环 + 微推镜呼吸，应急零素材扩容）**：
   当手头只有 1 条 10s 底片时，利用睡眠/依偎动作首尾柔顺的特点：`第1幕 正放全景 (0-10s)` → `第2幕 倒放无缝过渡 (10-20s，衔接帧像素差为 0，绝无跳剪)` → `第3幕 1.04x 中心柔焦微推镜特写正放 (20-30s)`。

```sh
# 校验 30s 三幕 12 句台词配置并查看耗时预估
python3 scripts/expand_30s_template.py --mode estimate --spec-30s examples/spec-milk-tea-30s.json

# 单底片 5 秒生成 30s 零跳帧无声底片 + 30s 循环伴奏轨
python3 scripts/expand_30s_template.py --mode pingpong \
  --template-dir templates/capybara_morning_10s \
  --out-dir templates/capybara_morning_30s
```

## 常见失败模式与速查修法

| 现象 | 根因 | 修法 |
| :--- | :--- | :--- |
| 角色嘴唇贴在对方脸上时还在说话 | 台词侵入了 `3.50s` 亲脸颊区间 | 在 `template_manifest.json` 设 `sfx_guard_zones`，门禁自动拦截 |
| 某句配音听起来像开了倍速 | 单句塞了十几个字，触发高倍压缩 | 按 `4.2~5.3 字/秒` 砍掉虚词，让 `atempo` 保持在 `1.0x~1.18x` |
| 台词字头慢半拍、对不上张嘴瞬间 | TTS 开头自带 `150~300ms` 空白静音 | `clone_and_dub_a1.py` 内置 `-36dB` 边缘静音裁切 + `20ms` 呼吸留白 |
| 网页 / 手机预览画面一顿一顿 | 原片 HEVC 编码或静态帧插帧产物 | 统一用 `H.264 High@L4.0 -pix_fmt yuv420p -movflags +faststart` 封装连续 24fps 3D 流 |
| 发布后被平台限流或侵权争议 | 未标 AI 合成 / 商用直接使用他人角色 | 发布勾选「AI 生成合成内容」标识；个人私享测试放私有云盘，长期商用换自建 3D/Live2D 原创角色模板 |
