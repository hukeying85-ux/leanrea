## 复现命令

```bash
cd skills/xhs-wallpaper-replica
SPEC=examples/koi-dream-6acb2a38/02-复刻/spec.json
ART=examples/koi-dream-6acb2a38/02-复刻/art
OUT=examples/koi-dream-6acb2a38/02-复刻

# 干净版 + 总图 + 封面（无 UI）
python3 scripts/phone_mockup.py all "$SPEC" --art-dir "$ART" --out "$OUT/壁纸" --format jpg
# 有 UI 版（几何按 spec.canvas 等比缩放；9:20 时与 --ui ios 一致）
python3 scripts/ui_overlay.py "$SPEC" --in "$OUT/壁纸" --out "$OUT/壁纸-有UI版" --format jpg
# 有无 UI 对照总图
python3 scripts/compare_sheet.py "$SPEC" --clean "$OUT/壁纸" --ui "$OUT/壁纸-有UI版" --out "$OUT/总预览图.jpg"
```

字体：`~/.fonts/Inter-Variable.ttf`（时钟）与 `~/.fonts/LXGWWenKai-Medium.ttf`（中文标题），本轮用 GitHub blobs API 拉取。
