## 复现

```bash
cd skills/xhs-wallpaper-replica
S=examples/simple-fresh-69af7ccc/02-复刻
python3 scripts/phone_mockup.py all $S/spec.json --art-dir $S/art --out $S/成图 --format png
python3 scripts/ui_overlay.py $S/spec.json --in $S/成图 --out $S/成图-有UI --format png
python3 scripts/compare_sheet.py $S/spec.json --clean $S/成图 --ui $S/成图-有UI --out $S/总预览图.png --format png
```

`spec.canvas` 决定交付画幅；`phone_mockup.py` 按 `ax` 把底图 cover 到 884×1845，`ui_overlay.py` 把 1440×3200 的 iOS 几何按 `k=884/1440, ky=1845/3200` 等比缩放，所以有 UI / 无 UI 版**同画幅**。
