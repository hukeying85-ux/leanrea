## 做法
1. 10 个场景按「朝 → 暮」排一天：日出 → 早餐 → 花田 → 树下午睡 → 雨中共伞 → 海边日落 → 摩天轮 → 星空 → 月下河灯 → 晚安。
2. 生图只画干净画面（提示词要求两只熊在下三分之一、上半部留空），不让模型写字。
3. 文字由脚本 `scripts/caption.py` 压上：`yf ♥ wsh`（Great Vibes 手写体 + 粉红心）/ `走过你的朝朝暮暮`（马善政毛笔楷书）/ `两个月纪念日`（霞鹜文楷小字）；
   文字块默认放在画面高度 37% 处（避开锁屏时钟），亮底用深玫瑰棕字 + 奶白柔光，暗底用奶白字 + 深色阴影；09 月下河灯放到 56% 避开月亮。
4. `无字版/` 是同一套没有文字的底图，想换句子或者只要画面时用；`手机UI预览/` 是 iOS 锁屏效果示意。
