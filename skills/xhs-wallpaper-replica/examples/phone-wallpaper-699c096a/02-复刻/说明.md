# 手机壁纸 · 花墙十景｜复刻说明

## 来源与规格

- 参考：徐一个愿望💳《手机壁纸》，笔记 `699c096a000000000b009cb4`（<https://xhslink.cn/o/3vhEnAitnnf>），9 张原片，**全部 1320×2868**。
- 原帖气质：奶白/米灰 plaster 墙面、爬藤玫瑰与彩色花丛、黑色复古壁灯/路灯、强烈但不刺眼的午后阳光与叶影、粉蓝天空、蝴蝶，配书法祝福语。
- 用户要求「一样风格但不能完全一模一样」→ 01–08 为**同风格变体重画**（对应原帖 9 张里的 8 个母题，花种、灯位、光线、取景都改过），09–10 为同风格新场景（雏菊老灯、紫藤垂影）。**本套不是逐张像素级复刻，也不是把原图换色。**
- **交付规格：1320×2868，10 张全部一致**，与原帖原图同尺寸。spec 里 `canvas` 固定；`ax` 按底图宽高比设置，保证宽幅底稿里的花与灯不被裁掉。
- 原帖的书法字/英文/红色印章一律不重画；壁纸本身保持无字无 UI，字和手机界面是两回事。

## 复现

```bash
cd skills/xhs-wallpaper-replica
S=examples/phone-wallpaper-699c096a/02-复刻
python3 scripts/phone_mockup.py all $S/spec.json --art-dir $S/art --out $S/成图 --format png
python3 scripts/ui_overlay.py $S/spec.json --in $S/成图 --out $S/成图-有UI --format png
python3 scripts/compare_sheet.py $S/spec.json --clean $S/成图 --ui $S/成图-有UI --out $S/总预览图.png --format png
```

`ui_overlay.py` 把 1440×3200 的 iOS 几何按 `k=1320/1440, ky=2868/3200` 等比缩放，因此有 UI / 无 UI 版**同画幅**，不是拿另一张图冒充预览。
