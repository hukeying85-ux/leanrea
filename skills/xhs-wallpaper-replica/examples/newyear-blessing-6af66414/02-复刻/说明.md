## 为什么字不由生图模型写

模型只负责纸、花枝、空白竖幅和圆印；文案由 `scripts/newyear_caption.py` 竖排压上去。
这样 10 张可以各自换句子，不会出现生图模型写错字/写繁体缺笔画的问题。

字体选择：`Ma Shan Zheng` 毛笔味更足，但缺 20 个常用繁体字（萬/順/歲/氣/財/運/連/錦…），初版出现方框；
改用 `LXGWWenKai-Medium`（字形覆盖完整、本身是楷书手写味），并对 alpha 做 3px 膨胀模拟毛笔厚度。

## 目录

```

02-复刻/
  spec.json      canvas=[1888,4096]；每页两条祝福 + 侧款 + 两条竖幅在底稿里的归一化坐标
  art/01..10.png 无字底稿（AI 生成，10 号为 08 号镜像调色）
  有字版/        10 张 1888×4096 干净 PNG（交付物）+ 总图.jpg + 封面-双机预览.jpg
  有字版-JPG-有UI/ 10 张同画幅 JPG 锁屏/主屏预览（只看不发）
  总预览图.png / .jpg  上排有字无 UI、下排有字有 UI，10 页对照
  文案.md / 说明.md
```

`无字版/` 和 `有字版-有UI/` 的 PNG 中间文件已删掉以控制仓库体积；用下面命令随时可再生。

## 复现

```bash
cd skills/xhs-wallpaper-replica
S=examples/newyear-blessing-6af66414/02-复刻
python3 scripts/phone_mockup.py build $S/spec.json --art-dir $S/art --out $S/无字版 --format png
python3 scripts/newyear_caption.py $S/spec.json --in $S/无字版 --out $S/有字版 --art-dir $S/art --format png
python3 scripts/phone_mockup.py sheet $S/spec.json --out $S/有字版 --format png
python3 scripts/phone_mockup.py cover $S/spec.json --out $S/有字版 --format png
python3 scripts/ui_overlay.py $S/spec.json --in $S/有字版 --out $S/有字版-有UI --format png
python3 scripts/compare_sheet.py $S/spec.json --clean $S/有字版 --ui $S/有字版-有UI --out $S/总预览图.png --format png
```

`newyear_caption.py` 会按 `art/` 的实际尺寸复现 `fit_canvas` 的 cover 裁切，把 spec 里的竖幅坐标投影到 1888×4096，并夹在画幅内，所以宽幅底稿也不会把字画到画面外。
