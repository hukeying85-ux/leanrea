# 角色卡 · 一二 / 布布（据抖音 @爱一二的布布《一二布布的三视图》6 张原图实测）

> 用途：给生图模型当「约束清单」。写提示词时逐条翻译成英文，遇到模型漂了就先回来查这张卡。

## 一、几何（两人完全一致，只有颜色不同）

| 项 | 值 |
|---|---|
| 头身比 | 约 1.6 : 1（头就是身体，头占总高 ~62%） |
| 脖子 | **无**。头与身体用一条横向弧线分出，头压在身体上 |
| 头形 | 上圆下略方的「碗盖」，正面最宽处在耳下方 |
| 身体 | 圆桶形，宽度约头的 55%，屁股略外扩 |
| 手臂 | 短棒状，贴身体两侧垂下，内侧一条 U 形线表示手臂内缘 |
| 腿 | 极短，正面两腿分开约 1/3 体宽，脚掌圆钝 |
| 侧面 | 后脑是一个大圆弧；尾巴是背后一个小圆 |
| 画布 | 1:1 正方形，底色 `#F7F5F0`，主体高约 85%，四周留白 |

## 二、配色（十六进制，实测取色）

| 部位 | 一二（白） | 布布（棕） |
|---|---|---|
| 身体 | `#FCFAF5` 近白奶 | `#D9A883` 暖沙棕 |
| 耳朵 | `#3A1F12` **实心深棕**（无内耳） | 外圈 `#D9A883` + 内耳椭圆 `#4A2A18` |
| 描边 | `#3A1F12`，等宽、无粗细变化 | `#4A2A18` |
| 腮红 | `#F0A8A2` 软粉，正圆 | `#FBDCA0` 奶油黄，正圆 |
| 鞋 | 深棕平底鞋（正面/背面都能看见） | **无鞋**，光脚圆钝 |
| 胸前 | 一个小小的深棕蝴蝶结/结扣 | 无 |

## 三、五官锚点

- 眼睛：两个实心圆点，直径约头宽的 7%，间距约头宽的 26%，与嘴同一水平线略上。
- 嘴：`w` 形（两个小弧），宽约头宽 10%，位于两眼正中偏下。
- 腮红：正圆，直径约头宽的 22%，贴在脸颊外侧、眼睛下方，左右对称。
- 侧视：只露 1 只眼 + 1 个腮红，嘴在靠近脸缘处；背面：**五官全无**。

## 四、可变项（只允许这几样变）

1. 视角：正面 / 侧面 / 背面 / 四分之三 / 俯视。
2. 道具：手持小花、小包等（原笔记没有，属于二次创作）。
3. 场景与背景（做壁纸/头像时才加）。

除此之外——**头身比、耳朵形状是否实心、有无鞋、腮红颜色、描边宽度**一律不许动。
这四项正是一眼认出「是不是一二布布」的全部信息。

## 五、评论区捞到的三条硬差异（比任何形容词都准）

1. 「一二的耳朵是实心，布布有内耳」— 来自原笔记评论区高赞回复。
2. 「一二穿了深棕色的鞋子，布布光脚」。
3. 「两人除了颜色其他都是一个模子刻出来的」——所以提示词里比例、四肢、画布规则可以完全复用，**只换配色块**。

## 六、建议提示词骨架（英）

```
Redraw the same character model sheet, same art style, 1:1 square canvas.
Subject: <species/身形一句话>，<视角>，centered.
- <body 配色 hex>，round head merging into round body, no neck
- <耳朵描述：solid dark ears / ears with dark inner oval>
- <眼/嘴/腮红：dot eyes, "w" mouth, <hex> circular blush>
- <手臂/腿/尾巴/鞋：有无 bow、有无 shoes>
- Thick uniform <描边 hex> outline of constant width, flat colors, zero gradient, zero shading.
Canvas: off-white #F7F5F0, generous margin, character ~85% height.
No text, no letters, no watermark, no shadow, no ground line, no props.
```
