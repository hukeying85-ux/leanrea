## 四、命名规范评分

| 规范 | 执行情况 | 评分 |
|---|---|---|
| 顶层编号 00–16 | 17 个编号库齐全，跳号无空缺 | A |
| 无编号库是否可辨 | `Arena-0fuye-DesktopBridge`、`Colab Notebooks` 是灰色/默认名 | C |
| 日期后缀 | 广泛使用 `_YYYY-MM-DD` / `_YYYYMMDDTHHMMZ` | A− |
| 版本后缀 | `v1.1.0`、`v1.3`、`v1/v2/v3` 并存，无统一语义 | C+ |
| 语言混用 | 中英混排（`healing-comic`、`xhs-archive` 与中文并列） | B |
| 未命名产物 | `Untitled0.ipynb` | D |
| 交付层标记 | 仅 05 号用了 `99 REA 交付` | B−（约定很好，未推广） |

**建议三条硬规则**（写进 00 号索引）：
1. `NN_主题（子主题1 / 子主题2）` —— 顶层；
2. `YYYY-MM-DD_内容_状态` —— 叶子（状态取 `草稿`/`成品`/`已发布`/`废弃`）；
3. `99_交付_对象_日期` —— 任何对外交付物统一 99 前缀。
