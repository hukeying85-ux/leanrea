## 三、视频简介（约 340 字）

```
先问一句：你上一次打开 App 没看到广告，是什么时候？

开屏五秒、下拉热搜、应用商店的轮播、一天十条「猜你喜欢」的推送，
还有那些点错一下就跳出来的快应用——它们不是 App 放的，
大部分是国产安卓系统自己带的开关，默认全开。

这期讲的工具是 GitHub 上的 android-ad-cleaner（中文名「肉呆去广告」，MIT）：
插上数据线、开 USB 调试，桌面客户端点五下就关完。
不 root、不刷机、不解锁；它只拨系统和 App 本来就有、只是藏得很深的开关，
改之前做备份，挂起的广告包一条命令就能还原。
广告组件挂起那一步要机主自己点头，搜索、负一屏卡片、
商店的安装更新、天气预警和快递提醒都保留。

需要提醒的三点：
1）只支持能连 adb 的安卓设备，原生鸿蒙（HDC）暂不支持；
2）机型脚本是逐台真机验证过的，你的机型不在列表里就别硬来；
3）系统 OTA 升级可能把开关推回默认，升级后重新跑一遍即可。

十页图只是把这件事讲清楚，真正动手还是看项目 README。
链接和免责说明放在置顶评论里。
```
