# healing-comic：从一篇长文到一套能直接发布的小红书漫画（含视频版）

一个 SKILL.md + 两个脚本（compose.py 合成 / ocr_layout.py 测量验收），不需要 MCP、不需要排版服务、不需要把中文交给生图模型。

**核心原则：一页 = 一个动作 + 一句台词 + 两个角色。** 治愈感来自「少」，不是来自画得多。

**第二原则（本项目反复验证）：一半的功夫在画图之前。** 内容规划（选题、钩子、对白、源文映射）决定这套图有没有人看完、记不记得住；版式和画风只决定它像不像。规划错了，复刻得再像也没用。

## 何时用 / 何时别用

- 用：长文、指南、PDF、课程笔记 → 小红书 6–9 页漫画套图（+ 视频版）；已有文字卡想换风格；想复刻某个爆款帖的版式装自己的内容；想做轻 IP 连载。
- 别用：要精确数据表格、法律/医疗条款原文、需逐字保留的长文（用知识卡片 skill）；20 格以上连载剧情、复杂分镜、多角色换装（见 `references/github-skills.md` 的条漫方案）。

## 全流程六阶段（本项目完整跑通过一遍）

```
A 内容规划 → B 版式 → C 底图 → D 合成+验收 → E 视频版 → F 发布
   ↓            ↓         ↓          ↓            ↓
storyboard  layout.json  art/     pages/       .mp4
+ copy 文档  (复刻时)    无字底图  + preview
```

每个阶段的产出物、工具、范例都在下文。**A 是灵魂，B–D 是骨架，E–F 是放大器。**

## A. 内容规划（画图之前做完，做成两个文档）

### A1. 选题：最小可用主题

不要「把整本书做成漫画」。13 章 104 条 → 一次只讲 **4–8 个点**。先问：**读者看完这一套能记住哪一句？** 写不出这句话就换角度。

两种经过验证的选题套路：

| 套路 | 结构 | 适用 | 范例 |
|---|---|---|---|
| **清单型** | 「XX 从不做的 N 件事」（负面清单） | 有明确行为边界的指南 | 《引导型恋人，从不做的 8 件事》 |
| **深挖型** | 单条展开成 3 页（判断→做法→证据） | 一个反直觉的概念 | 3.7 承诺要小而可兑现 |

### A2. 钩子 + 情绪曲线

- **钩子**放封面副题和正文第一行。好钩子 = 具体数字 + 自我代入：「第 6 张，很多人天天在做」「你中过几件？」。
- **情绪曲线**是治愈漫画的引擎。参考帖的固定句式是「我以为是…，其实是…」（过度包容→其实是一种疏远）；我们的引导型翻版是**「处境 → 引导」**：先让读者在布布身上看到自己，再让一二给出不指责的出路。每页一个小转折，8 页叠成一个大转折。

### A3. 源文映射表（每页可溯源）

分镜表每页标**源文章节**。三个作用：① 防止文案跑偏成自创鸡汤；② 发布时置顶评论给出处，CC BY 4.0 署名合规；③ 读者问「这是哪来的」有答案。映射表直接写进 copy 文档（范例见 `references/copy-复刻版-8件事.md` 的分镜列）。

### A4. 对白设计：触发句 → 引导句（两拍结构）

这是把「知识」变成「戏剧」的关键。每页两拍：

- **触发句**（伴侣/布布）：读者的真实处境，口语、≤12 字、带一点委屈或试探——「有点沉……」「手机给你，随便看。」「明年一定带我去吗？」
- **引导句**（引导者/一二）：**可直接说出口的实操句**，≤12 字、不指责、给选择权——「你先试，我在旁边。」「不看，我信你。」「先定这周三，我来订位。」

硬规则：**每句引导句必须能映射回源文的实操建议**（第一句怎么说 / 怎么接 / 红线），映射不回去就改。读者每页学到一句能当天用的话，这是收藏率的来源。

### A5. 页面文案三层（复刻版式字段）

| 层 | 字数 | 作用 |
|---|---|---|
| 标签 | 4–8 字 | 页身份，顶部居中（清单型可去掉编号，原帖无编号） |
| 点题句 | ≤14 字 | 页金句，中幅居中；清单型用「X 是 Y」句式，深挖型用判断句 |
| 气泡 ×2 | 各 ≤12 字 ×≤3 行 | 触发句 + 引导句 |

### A6. 发布文案（与页面同天设计，不是发布时才写）

- **标题** ≤20 字，主推 + 备选各一（「这 8 件事，稳得住的伴侣一件都不做」17 字）。
- **正文** ~330 字：钩子开场 → 一句总纲 → N 条清单（每条 = 页标签 + 点题句）→ 一句升华 → 互动引导（「你中过几件？评论区认领👇」）。页面上放不下的源文长句全部进正文。
- **话题**：6–8 个，主题词 + 泛流量词 + IP 名（#引导型恋人 #亲密关系 #一二布布）。
- **置顶评论**：出处 + 许可 + 免责（不是心理咨询；暴力/成瘾/自伤先找专业帮助）。

**产出物 1：`storyboard.md`**（分镜表：page / 源文 / 动作 / 标签 / 气泡 / 画面）；**产出物 2：`copy-<主题>.md`**（测量数据 + 分镜 + 发布文案，范例见 references/）。

## B. 版式（两条路线，二选一）

### B1. 复刻路线（有参考帖）—— 四步，全部可量化、可验收

1. **测量**：`python3 scripts/ocr_layout.py --refs <原图目录> --out layout.json`
   中文 OCR 把参考图的三类文字区读出来——顶部标签（y<12% 且水平居中）、中幅点题句（y 50–66% 且居中）、其余=气泡（锚点=文字框中心的比例坐标）——并量出墨色、字号、气泡底色/描边/形状充实率、纸纹、色板。
   **别只用肉眼盯色板：结构（几段式、点题句在哪、气泡落在哪）才是版式的骨架。**《毁掉关系的八种做法》实测为两段式（标签→上半场对白→点题句→下半场对白）；只量像素时它会被误判成单场景——这是本项目最重要的教训。
2. **底图**：不做文生图，**以参考图本身为底做「去字编辑」**（remove all text and speech bubbles, keep everything else；场景需替换的按分镜改）。笔触、纸纹、构图、角色天然继承。生成后 `--verify-art` 复验。
3. **合成**：spec 用 `label / reveal / bubbles[{lines, anchor}]` 字段（锚点照抄 layout.json），`compose.py --layout xhs2`。
4. **验收**：`ocr_layout.py --verify-page 成品.png --spec spec.json` 逐页核对文字内容与落位。

实测常量表（《毁掉关系的八种做法》8 图，可直接套用）：

| 项 | 实测值 |
|---|---|
| 画布 | 1080×1447（3:4） |
| 结构 | 标签 → 上半场对白 → 点题句 → 下半场对白 |
| 标签 | 66px 居中，中心 y 0.073（范围 0.063–0.095） |
| 点题句 | 56px 居中，中心 y 0.568（范围 0.560–0.606） |
| 气泡 | 白底 + 墨描边 2–3px，形状充实率 0.50–0.68（手绘云朵感 → 微扰椭圆） |
| 气泡文字 | ≈34px，行距 ≈44px；锚点节奏：上拍 y≈0.15、下拍 y≈0.65，随说话人左右交替 |
| 墨色 | 中位 #32150D（各页 46–92 不等，取中位而非平均） |

**进阶：结构复刻成功后换自己的场景。** 版式骨架不动，对白换成 A4 的触发句→引导句，底图以复刻底图为锚做场景改写——角色方位按气泡锚点指定（谁说话气泡靠谁），动作直接画引导行为本身（悬着不接的手、放下热茶踮脚走、把手机推回去、日历圈住近日期）。范例：`examples/spec-xhs8c.json` + `examples/art-xhs3/`。

### B2. 海报路线（无参考帖，taste-skill 审校版）

排版规则对照 [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)（108k★ anti-slop skill）逐条审过：删 eyebrow 与页码、全左对齐、一个超大一个小、无渐变无阴影无细线、标题两行以内、图片上的文字用中性描边光环（其唯一允许的例外）、渲染后用 gate 实测字宽行数。对网页规则不适用的两条按媒介惯例保留：对话气泡的描边（漫画的语义元素）与气泡尾巴。规格：1080×1440、大标题 80px Medium + 支持句 42px + 台词 46px + 页脚 26px，上 1/3 与下 1/4 留白，72px 左边线。

## C. 底图生成（无字铁律 + 角色一致性）

### C1. 角色卡（一字不差写进每页 prompt）

- **一二**：白色小熊猫——纯白圆身、实心黑圆耳、黑色熊猫眼罩、小眼睛、黑蝴蝶领结、白色短手、黑色小脚。
- **布布**：奶茶棕小熊——略大一圈、圆耳、奶白口鼻、黑点眼、小鼻子、短粗四肢；**原作不戴围巾，别加**。

> ⚠️ **版权**：「一二和布布」是黄小 B 2018 年创作的受保护 IP。高相似版（挂原图参考/去字编辑）建议个人笔记使用并标 AI；商用 / 长期做号换 `examples/art-original/` 原创角色（「白团子 + 阿棕」，同一套 spec 重跑即可）。

### C2. 提示词模板（复制改 SCENE 即可）

```
Use the two characters and the exact art style from the reference images.
CHARACTER 1 (white panda cub): small chubby pure-white round body, two solid
black round ears, two black oval panda eye patches, small simple eyes, a small
black bow tie, short white stubby arms, little black feet.
CHARACTER 2 (brown bear cub): slightly bigger chubby milk-tea-brown round
body, small round ears, pale cream muzzle, small black dot eyes, tiny nose,
short stubby limbs, no scarf.
Thin clean dark outlines, completely flat coloring, plain warm-white
background, soft pastel accents, no gradients, no shading, no texture, simple
rounded shapes, cozy warm, vertical portrait 3:4, one single scene,
no panel borders.

SCENE: <一个动作、一个情绪、最多两个道具，角色方位按气泡锚点写明 LEFT/RIGHT>

Keep the top 12% of the image as calm empty warm background (light tone, even
for evening scenes); keep the corners near each planned bubble as simple calm
areas. CRITICAL: absolutely no text, no Chinese characters, no letters, no
numbers, no captions, no speech balloons, no speech bubbles, no watermark,
no logo, nothing written on any object.
```

### C3. 三条铁律（都是踩过的坑）

1. **所有中文一律不交给图片模型**——错字、糊字、伪字必然出现；连「123」都别让它画。气泡由脚本画。
2. **复刻场景时优先「编辑参考图」而不是文生图**——风格天然继承；编辑时场景别轻易换，换场景 = 换底图再验一次。
3. **夜景/暗调页要显式约束顶条为亮纸色**——否则顶部标签区域会发灰（实测一页 156 vs 目标 220+）。

### C4. 生成后必验 + 残留修复

`ocr_layout.py --verify-art`（OCR 残留 = FAIL；主色互覆盖而非只比第一名颜色；纸纹对比）。小字符残留（手机屏上的 "CT"、窗边 "88"）先按笔画连通域判定（**填充率 <0.3 = 笔画状文字**，实心物体不会这么低），确认真文字后用 OpenCV `cv2.inpaint(TELEA)` 修掉，不耗生图次数。

## D. 合成与验收

```sh
python3 scripts/compose.py spec.json --layout xhs2 \
  --font LXGWWenKai-Regular.ttf --font-medium LXGWWenKai-Medium.ttf \
  --art-root examples --outdir pages --html --contact-sheet
python3 scripts/ocr_layout.py --verify-page pages/复刻02.png --spec spec.json
```

- compose.py 渲染即 gate：超宽 / 超行 / 气泡出界直接报错；`art/` 永不写入，改文案只重跑。
- verify-page 逐页核对：文案存在、位置正确（标签在顶 / 点题句在中幅 / 气泡对锚点 ±0.08）、无多出文字。内置三种 OCR 噪声容忍：形近字误读（于/乎、上/止，difflib ≥0.8）、一行拆多框（片段窗口相似度）、重叠重读（几何重叠）。
- 没有中文字体先跑 `scripts/fetch_font.sh`（霞鹜文楷，SIL OFL 1.1）。

## E. 视频版（图文发完 1–2 天后再发，试流量）

同一套 pages 直接拼轮播视频，ffmpeg 一条命令的配方（9 页 36s 版实测通过）：

```
每页：scale 到 2160×2880 → zoompan 缓推（z: 1→1.06）或缓拉（1.06→1，奇偶页交替）
      → 输出 1080×1440 @30fps
页间：xfade=fade:duration=0.5，offset_k = Σ(L0..Lk) − (k+1)×F
时长：封面 4s、内容页 4.5s；轨道：无音轨（发布时 App 内配乐）
编码：libx264 -crf 21 -movflags +faststart  →  9 页 ≈ 11MB
```

小红书可直接发；无音轨是特性不是缺陷——站内配乐能蹭热度曲。想要角色真动起来（耳朵抖、走路）需即梦/可灵类图生视频工具：把 C2 的 SCENE 改写成运动描述（谁动、怎么动、镜头怎么走）逐页投喂。

## F. 发布清单（四查 + 合规）

- **缩略图查**：`preview.jpg` 缩到 200px 宽，封面标题还认得出吗？
- **落位查**：verify-page 全 PASS（复刻版）；角色查：蝴蝶结/耳朵有没有丢，丢了用封面作参考重生成。
- **字数查**：台词 ≤12 字、标签 ≤8 字、标题 ≤20 字、正文 ≤1000 字、单篇 ≤18 张（推荐 6–9 页 + 视频）。
- **合规查**：**勾选「AI 生成合成内容」标识**（小红书 2026-02 起强制，未标识限流）；署名原书 + 许可证（本套：正文 CC BY 4.0 / 代码 MIT / 字体 OFL）；保留「不是心理治疗；暴力/成瘾/自伤先找专业帮助」免责句（放置顶评论）。

## 风格为什么好抄（量化拆解）

| 特征 | 做法 | 省掉了什么 |
|---|---|---|
| 两个圆形角色 | 头身比 1:1，只靠耳朵/领结区分 | 表情演技、人体、透视 |
| 三色平涂 | 白 + 棕 + 一个点缀色 | 上色、光影、背景绘制 |
| 一页一动作 | 不画分镜、不画时间流动 | 分镜设计、跨格连贯 |
| 一句对话 | 口语、≤12 字、带一点反差萌 | 旁白、论述、信息密度 |
| 情绪转折 | 「处境→引导」/「我以为是…其实是…」 | 说教，换成被理解的感觉 |
| 大量留白 | 顶部 12% + 气泡角干净 | 排版拥挤、缩略图看不清 |

## 常见失败模式

| 现象 | 原因 | 修法 |
|---|---|---|
| 复刻「不像」但说不出哪不对 | 只量了色板没量结构 | ocr_layout.py 量出几段式/锚点，结构是骨架 |
| 中文错字/糊字/乱码 | 让生图模型写字 | 无字底图 + compose.py |
| 底图冒出杂字（屏上/窗上） | 模型习惯性补细节 | verify-art 逐页 OCR；inpaint 或重生成 |
| 第 3 页角色配饰漂移 | 每页单独生成 | 封面/已验底图作参考 + 角色卡逐字复用 |
| 顶条发灰 | 夜景整页暗 | prompt 显式约束顶 12% 亮纸色 |
| 气泡压到角色脸上 | 锚点随手填 | 锚点抄实测值；底图 prompt 按锚点留净区 |
| 一页塞 4 个概念 | 想保留原文结构 | 一页一个动作，其余进正文配文 |
| 做成 20 页文字卡 | 旧素材惯性 | 砍到 6–9 页 |
| 引导句像说教 | 文案没映射源文 | A4 硬规则：每句映射回指南实操建议 |
| 要商用 | 高相似版有 IP 风险 | 换 `examples/art-original/` |
| 被限流 | 未标 AI | 发布勾选 AI 标识 |
