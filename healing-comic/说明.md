## v2 排版改了什么（对照 taste-skill 规则）

- 删掉页眉小标签（eyebrow）和右上角页码（index numbering）——出处并入页脚一行
- 大标题 80px Medium 一行 + 副标题 42px（原为两行同号 66px），信息流缩略图更醒目
- 台词气泡内左对齐（原居中），全部文字共享 72px 左边线
- 删掉装饰性波浪下划线；无渐变、无阴影、无细线
- 文字加奶油色描边光环（图上文字可读性的标准做法）
- 渲染后自动 gate：标题/副标题/页脚超宽、气泡超 3 行直接报错

## 改文案 / 补页

1. 改 `排版配置_spec.json` 里的 `title` / `subtitle` / `bubble` / `footer`；
2. 重跑（需要 Python + Pillow + 中文字体 Regular/Medium 各一）：

   ```sh
   python3 scripts/compose.py examples/spec.json \
     --font <Regular.ttf> --font-medium <Medium.ttf> \
     --art-root examples --outdir examples/pages --html --contact-sheet
   ```

3. 脚本与完整技能在 GitHub：
