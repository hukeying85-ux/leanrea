## 改文案 / 补页

1. 改 `排版配置_spec.json` 里的 `title` / `bubble` / `footer`；
2. 重跑（需要 Python + Pillow + 任意中文字体）：

   ```sh
   python3 scripts/compose.py examples/spec.json \
     --font <中文字体.ttf> --art-root examples \
     --outdir examples/pages --html --contact-sheet
   ```

3. 脚本与完整技能在 GitHub：
