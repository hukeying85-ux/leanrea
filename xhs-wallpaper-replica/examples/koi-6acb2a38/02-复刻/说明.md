# 第 31 轮 · 锦鲤入梦 锁屏壁纸 · 生产说明

## 这是什么

@Nihility《锦鲤入梦｜锁屏壁纸》（[分享链接](https://xhslink.cn/o/3qz2uQpojFp)，笔记 `6acb2a3800000000120390ba`），
原帖 **3 张 853×1844 无水印 PNG**（01 双机海报「Fortune in Flow」，02 锁屏，03 主屏）。
本轮把 3 张原片逐张复刻 + 7 张同风格新场景，做成 **10 张 1440×2560（9:16 跟原帖）**，
并且按用户要求**同时交付无 UI 版与有 UI 版**，原片与结果分两个文件夹推上 Google Drive。

- 画风：国风工笔 + 水彩晕染 —— 暖月白手工纸底、青碧水色、淡金描线与金箔点
- 主体（写进提示词固定串）：
  - 白锦鲤 = white-cream koi with gold scales and long translucent flowing fins
  - 红锦鲤 = vermilion-orange koi with white scales and a long flowing tail
  - 环境 = celadon watercolor ripples, gold leaf flakes, warm moon-white paper
- 原则：壁纸本体（无 UI 版）里没有时钟、没有图标、没有 Home 条；「有 UI 版」只是装机预览。
- 原帖的「时来运转」四字与小署名 **不入图**（提示词强制去掉文字），中文全部由脚本叠加。

## 复现命令

```bash
cd xhs-wallpaper-replica/examples/koi-6acb2a38/02-复刻
python3 ../../../scripts/phone_mockup.py all spec.json --art-dir art --out 壁纸 --format jpg --cjk-font ~/.fonts/LXGWWenKai-Medium.ttf
python3 ../../../scripts/ui_overlay.py spec.json --in 壁纸 --out 壁纸-有UI版 --format jpg
```

Drive 交付件用 `--format png` 重跑一份。

## 生图提示词要点

- 本轮实测：**带 images 参考图 + 长提示词会 `generation failed`**；换成纯文字长提示词、或参考图 + 极短提示词都能过，最稳的是「纯文字长描述 + 固定风格串」。
- 去字句式（沿用第 30 轮，有效）：`No text, no letters, no watermark, no signature, no border.`
- 底图统一 768×1376，再由 `phone_mockup.py` 放大到 1440×2560。
