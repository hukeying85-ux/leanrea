## 复现步骤

```bash
# 1. 抓取原图（沙箱走 tools/xhs-relay）
git add tools/xhs-relay/queue.json && git commit -m "xhs-relay: queue 6aea9153" && git push
# runner 完成后：
git pull --rebase

# 2. 生成底图
# 01-05 A 模式去除对白气泡；06-10 B 模式同风格动物睡衣新场景

# 3. 合成与拼版
python3 xhs-wallpaper-replica/scripts/painting_set.py \
  xhs-wallpaper-replica/examples/bubu-together-6aea9153/02-复刻/spec.json \
  --art-dir xhs-wallpaper-replica/examples/bubu-together-6aea9153/02-复刻/art \
  --out xhs-wallpaper-replica/examples/bubu-together-6aea9153/02-复刻/成图 \
  --format png \
  --cjk-font ~/.fonts/LXGWWenKai-Medium.ttf

# 4. 生成封面与 iOS 锁屏预览
python3 xhs-wallpaper-replica/scripts/phone_mockup.py build \
  xhs-wallpaper-replica/examples/bubu-together-6aea9153/02-复刻/spec.json \
  --art-dir xhs-wallpaper-replica/examples/bubu-together-6aea9153/02-复刻/art \
  --out xhs-wallpaper-replica/examples/bubu-together-6aea9153/02-复刻/手机UI预览 \
  --ui ios \
  --clock-font ~/.fonts/Inter-Variable.ttf \
  --cjk-font ~/.fonts/LXGWWenKai-Medium.ttf
```
