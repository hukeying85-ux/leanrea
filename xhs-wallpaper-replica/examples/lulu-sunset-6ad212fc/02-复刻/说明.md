# 第 29 轮 · 和你一起奔夕阳 噜噜噜妹 · 生产说明

## 这是什么

回到**第 12 轮**那条笔记：@等噜噜《和你一起奔夕阳 噜噜噜妹壁纸》（[分享链接](https://xhslink.cn/o/5thkO8Kd6jg)，笔记 `6ad212fc000000001802d6be`，
作者主页 `6ab08e41000000001400c401`），原帖 **5 张 1080×1920 无水印 PNG**。
本轮把 5 张原片逐张复刻 + 5 张同风格新场景，做成 **10 张 1440×2560（9:16 跟原帖）**，
并且按用户要求**同时交付无 UI 版与有 UI 版**，原片与结果分两个文件夹推上 Google Drive。

- 画风：写实毛绒玩偶摄影感 —— 细腻绒面、浅景深、黄昏逆光、暖琥珀雾
- 角色（写进提示词固定串）：
  - 噜噜 = chubby round yellow plush, tiny orange fruit with two green leaves on its head, white watermelon-print shorts with a mint-green waistband
  - 噜妹 = smaller yellow plush, fluffy white lace bonnet with a pink bow, tiny orange fruit on top, pale pink strawberry-print ruffled dress
- 原则：壁纸本体（无 UI 版）里没有时钟、没有图标、没有 Home 条；「有 UI 版」只是装机预览

## 提示词骨架（实际使用）

A 模式（01–05 复刻）：

```
Recreate this exact image as a clean phone wallpaper, same scene, same camera angle, same composition.
Photorealistic plush-toy photography look: soft fleece texture, shallow depth of field, golden-hour backlight.
Two plush toys only, ANIMALS/creatures not humans: <噜噜串>; and <噜妹串>.
Scene: <场景 + 动作 + 光线>.
9:16 tall portrait. Keep the top quarter calm sky and the bottom ninth calm grass/water.
No text, no letters, no UI, no clock, no watermark, no signature, no border.
```

B 模式（06–10 新场景）：把开头换成
`Use the attached image ONLY as a reference for the art style, the two plush characters, the soft fleece texture and the golden-hour light. Paint a completely NEW scene as a clean 9:16 phone wallpaper.`

- 10 张一次全过，无返工；角色串照搬第 12 轮，服装细节（小橘子 / 西瓜花短裤 / 白荷叶边帽 / 草莓裙）无漂移。
- 生图输出 768×1376，与 9:16 差 0.03%，`phone_mockup.py` 零裁切。
- 已检查右下角：本轮**没有**生图角标，无需克隆修补。

## 复现命令

```bash
cd xhs-wallpaper-replica/examples/lulu-sunset-6ad212fc/02-复刻
S=../../scripts

# 无 UI 版（壁纸本体）——画幅跟随 spec.canvas=1440×2560
python3 $S/phone_mockup.py all spec.json --art-dir art --out 壁纸 --format jpg \
        --cjk-font ~/.fonts/LXGWWenKai-Medium.ttf
python3 $S/phone_mockup.py build spec.json --art-dir art --out /path/to/无UI --format png

# 有 UI 版（iOS 锁屏/主屏叠层，按 canvas 等比缩放同一套几何）
python3 $S/ui_overlay.py spec.json --in 壁纸 --out 壁纸-有UI版 --format jpg
python3 $S/ui_overlay.py spec.json --in /path/to/无UI --out /path/to/有UI --format png \
        --date "Saturday, November 7" --time 17:20      # 日期时间可换
```

`phone_mockup.py` 本轮改了两处：`fit_canvas` 的 `size` 参数改为可传，
`main()` 里 `W, H = spec.get("canvas", [W, H])` —— 以前画幅写死 1440×3200，9:16 的轮次会被裁。
