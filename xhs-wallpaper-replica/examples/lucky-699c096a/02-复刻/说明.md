# 第 33 轮 · 手机壁纸 · 白墙花影 · 生产说明

## 这是什么

@👒徐一个愿望💳《手机壁纸》（[分享链接](https://xhslink.cn/o/3vhEnAitnnf)，笔记 `699c096a000000000b009cb4`），原帖 **9 张 1320×2868**。
风格：**实景摄影 —— 白墙 / 爬藤玫瑰 / 铁艺壁灯 / 树影，配竖排毛笔字 + 红印章**（治愈·顺遂向）。
按用户要求「一样风格但不能完全一模一样」：**9 张全部重新布景配文**，不逐张照抄；第 10 张同风格新场景。

## 关键做法

| 环节 | 做法 |
|---|---|
| 底图 | `generate_image` 只出**无字实景照片**（白墙+花+灯+影），10 张一次过 |
| 中文 | 全部由 `scripts/card_typeset.py` 用马善政毛笔体竖排绘制（**从不进生图**） |
| 印章 | 每页一枚朱红小方印（顺/乐/花/愿/安/喜/欢/生…） |
| 画幅 | 底图 768×1376 → `fit_cover()` 等比放大**居中裁切**到 1320×2868（本轮修掉了旧脚本的拉伸 bug） |
| 可读性 | 字压在有纹理的老墙上时用 `halo` 描边（08 号「人间欢喜」用了 11px 米白描边） |

## 踩坑

- `card_typeset.py` 之前把底图 `resize` 到目标画幅（会拉伸），本轮改为 `fit_cover()` 等比裁切。
- 竖排字在花墙/斑驳老墙上会「融进背景」→ 用 `halo` 描边，或把 `vertical_x` 挪到纯白墙面。
- 印章要跟最后一列字留出 `fs.size*0.6` 的间距，否则会压住字尾。
