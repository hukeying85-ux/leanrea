@阿倾哥哥✨《祝福文字 新年壁纸》（[分享链接](https://xhslink.cn/o/3kQq76Fee2O)，笔记 `6af66414000000002203bdb3`），原帖 **4 张 1888×4096**。

## 关键做法

| 环节 | 做法 |
|---|---|
| 底图 | `generate_image` 只出**无字古绢卷轴**（绢纹、霉斑、断裂、花卉/山水），10 张 |
| 满幅化 | 生图给的是"挂在墙上的卷轴"，带墙面和挂杆 → 按每张构图**手动裁切**卷轴主体，再等比放大裁到 1320×2864，最后 `UnsharpMask` 补锐 |
| 书法 | `card_typeset.py` 新增 `strips`（多宣纸条）+ `seal_stamp`（方印/圆印）；宣纸条是带透明度的米白矩形，字用马善政毛笔体竖排 |
| 文案 | 10 组全新（岁岁常欢愉·年年皆胜意 / 朝朝如愿 / 喜乐平安·诸事顺遂 / 前路坦荡 / 所求皆得偿·所行皆坦途 / 心宽福自来·人安百事顺 / 春山可望 / 福满华堂·喜盈门庭 / 鸿运常相随·好景遂人愿 / 光阴不老·故人不散） |
| 锁屏安全区 | 竖排字 `top` 全部下移到 0.32–0.50 起笔，避开时钟与日期 |

## 复现命令

```bash
cd xhs-wallpaper-replica/examples/cny-6af66414/02-复刻
python3 ../../../scripts/card_typeset.py build spec.json --art-dir art --out 壁纸 --format jpg
python3 ../../../scripts/ui_overlay.py  spec.json --in 壁纸 --out 壁纸-有UI版 --format jpg
# Drive 交付 PNG 把 --format 换 png
```

> 注意：`build` 读的是 `art/NN.png`，本轮合成用的是裁切后的 `art/bgNN.png`，
> 所以复现前先把 `bgNN.png` 复制成 `NN.png`（或用 `--art-dir art-bg` 并改名）。

## 踩坑

- 生图把「古画绢本壁纸」理解成**挂在墙上的卷轴**，10 张里有 6 张带墙面/挂杆/流苏 → 必须按每张构图手工定裁切框，不能统一 `fit_cover`。
- `strips` 分支必须放在 `blob`（贴纸云朵块）之前，否则会先被画上红色云块。
- 印章 y 坐标要跟着字下移，否则锁屏时会留在顶部空白处、跟字脱节。
