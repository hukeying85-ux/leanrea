# 第 32 轮 · 简单清新壁纸 · 生产说明

## 这是什么

@齐齐《简单清新壁纸》（[分享链接](https://xhslink.cn/o/24CQFIRp9Er)，笔记 `69af7ccc000000001a02eba0`），原帖 **9 张 884×1920 无水印**。
风格：**纯色/纸纹底 + 可爱插画 + 贴纸底块 + 手写体大字祝福**（清新文案卡片）。
本轮 01–09 逐张复刻 + 10 同风格新场景，交付 **1326×2880**（与原帖 884×1920 等比放大 1.5×，比例 0.4604 完全一致）。

## 关键做法：中文不进生图

生图模型写中文必出错字，所以这一轮：

1. `generate_image` 只出**纯色或纸纹底 + 角落插画 + 大块留白**（10 张全部无字，中文提示词一个不给）；
2. `scripts/card_typeset.py` 用字体把标题、英文小字、竖排落款、印章、胶囊小字、贴纸小图标全部画上去。

- 标题字体：`~/.fonts/ZCOOLKuaiLe-Regular.ttf`（圆润可爱，对应原帖的圆体手写）/ `~/.fonts/MaShanZheng-Regular.ttf`（马善政毛笔，对应国风页）
- 副字体：`LXGWWenKai-Medium.ttf`
- 贴纸小图标（星、金币、花、小熊、蝴蝶结、光点）都是脚本矢量画的，不依赖素材

## 复现命令

```bash
cd xhs-wallpaper-replica/examples/fresh-69af7ccc/02-复刻
python3 ../../../scripts/card_typeset.py build spec.json --art-dir art --out 壁纸 --format jpg
python3 ../../../scripts/ui_overlay.py  spec.json --in 壁纸 --out 壁纸-有UI版 --format jpg
```

Drive 交付 PNG：把 `--format` 换成 `png` 各跑一次。

## 踩坑

- 生图带参考图 + 长提示词容易 `generation failed`；这轮 10 张都用**纯文字短提示词**，10/10 一次过。
- `card_typeset.py` 的 `title_ink` 默认跟着 `blob` 走：有底块 = 白字，无底块 = 用 `ink` 色；想反色就显式写 `title_ink`。
- 文案落在页面上半部时，锁屏时钟会压住文字 → 这类页把 `title_cy` 放到 0.5 以下。
